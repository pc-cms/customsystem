# Other Incomes → приход в кошелёк

## Что происходит сейчас

В Мванзе за август внесены прочие доходы на 111 407 974 TZS (License 60M, Boss Pessa 48.5M, JP 2.24M, Dealers Tips 535 500, бонусы). Снимок баланса их видит: `incomes.other = 111 407 974` — то есть **Expected пересчитался корректно**.

Не изменилась вторая половина сверки: **Actual**. Деньги нигде не легли в кошелёк — в `fin_wallet_tx` по этим доходам проводок нет. Поэтому Expected вырос, Actual остался прежним и Variance ушёл в большой минус. Ощущение «кошелёк не пересчитался» — именно от этого.

## Что будет сделано

1. При вводе прочего дохода (Other Incomes) добавить поле **Wallet** — куда физически пришли деньги (Safe TZS, NBC, M PESA и т.д.).
2. При сохранении дохода система автоматически создаёт приходную проводку в этом кошельке (Money In) на ту же сумму, дату и валюту — Actual и Expected растут одновременно, Variance не «разъезжается».
3. Правка суммы дохода обновляет связанную проводку, удаление/сторнирование — снимает её. Двойных проводок не будет: связь один-к-одному по ссылке на запись дохода.
4. Кошелёк — необязательное поле: если деньги ещё не поступили физически (или это техническая корректировка), доход можно записать без кошелька, как сейчас.
5. Существующие 6 записей Мванзы за август остаются без проводок; после релиза их можно перевыбрать кошелёк вручную, либо (по вашему слову) проставлю проводки разово через данные.

## Технические детали

- Миграция: колонка `wallet_id uuid references fin_wallets(id)` в `fin_other_incomes`; триггер AFTER INSERT/UPDATE/DELETE, пишущий/обновляющий строку в `fin_wallet_tx` (`kind='income'`, `ref_table='fin_other_incomes'`, `ref_id=NEW.id`, `amount`, `amount_tzs = amount*fx_rate`, `business_date`). При сторнировании (`reverses_id` / `reversed_by_id`) — обратная проводка, по образцу логики office-расходов.
- `src/hooks/use-other-incomes.ts`: прокинуть `wallet_id` в create/update; инвалидации `fin-wallet-tx` / `fin-wallet-bal-asof` / `fin-balance-snapshot` уже есть.
- UI формы Other Incomes: селект кошелька из `useFinWallets` (валюта дохода подставляется из кошелька), отображение колонки Wallet в списке.
- Поднять версию в `package.json`.
