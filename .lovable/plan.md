# Monthly Report: удаление записи рядом с карандашом

## Как сейчас

В Monthly Report (Finance → Monthly Report) при включённом Edit mode раскрытая категория показывает список расходов, и у каждой строки есть только карандаш. Карандаш открывает диалог, где уже можно сменить **Category**, кошелёк, сумму, валюту и описание — то есть переклассификация строк вроде «Google Workspace CRDB USD» делается через него. Кнопки удаления в этом списке нет — удалять сейчас можно только на странице Expenses.

## Что добавляем

- Рядом с карандашом в строке расхода — иконка корзины (Trash2).
- Клик открывает подтверждение: дата, описание, сумма и предупреждение, что запись удаляется без возможности восстановления.
- После подтверждения запись удаляется, таблица и все зависимые суммы (категория, итог месяца, кошельки) пересчитываются.
- Кнопка видна там же, где карандаш — в Edit mode для ролей с правом правки финансов (finance_manager / super_admin). Для остальных ничего не меняется.
- Удаление пишется в журнал (кто, когда, какая запись, сумма, категория), как и на странице Expenses.

## Технические детали

- `src/pages/finances/FinancesMonthlyReportPage.tsx`: в ячейке действий строки расхода (сейчас только `Pencil`) добавить вторую кнопку `Trash2`; проп `onDeleteExpense` пробросить из корневого компонента через `CategoryTable` → `Row`, как сделано для `onEditExpense`.
- Подтверждение — существующий `ResponsiveDialog` (страница уже его импортирует), состояние `deleteRow`.
- Мутация — существующий `useCancelExpenseAsManager` из `src/hooks/use-expenses.ts` (delete + `EXPENSE_CANCELLED` в лог, RLS решает право). Дополнительно инвалидировать ключи `fin-monthly-report`, `fin-wallet-tx`, `fin-wallet-balances`.
- Бэкенд и БД без изменений.
- Версию приложения повысить после внесения правок.
