# Фильтры — только реально встречающиеся значения

Цель: везде, где есть кнопки/списки фильтрации, показывать только те варианты, по которым в загруженных данных действительно есть записи. Пустые варианты убираем полностью.

## Где применяем

1. Касса → History (главный случай):
   - Cashless: список провайдеров строится из записей дня, а не из зашитых MTN / Tigo / Airtel / Halopesa;
   - Cage transfers и Cash checks: кнопки Live / Slots показываются только если такие записи есть; если источник один — выбор не нужен.
2. Admin → AM Budget: фильтр «Reason» показывает только те причины, которые встречаются в загруженных строках (сейчас всегда пять фиксированных).
3. Marketing → Campaigns: фильтр статуса — только статусы, которые есть в списке кампаний.
4. POS → Charges: фильтр статуса (open / settled / voided) — только встречающиеся.
5. Office → Tips & Bonuses: переключатель типа — только те типы, которые есть в выбранном периоде.
6. Guests → фильтр категорий игроков: только категории, которые встречаются среди гостей дня.

Во всех случаях кнопка/пункт «All» остаётся всегда, и если выбранный фильтр исчез при смене дня или периода, выбор автоматически возвращается на «All», чтобы список не оказался пустым.

Ничего нового на экраны не добавляем — только убираем пустые варианты. Подсчёты, отчёты и печать не меняются. Формы ввода (открытие/закрытие смены, пересчёты денег, редактирование записей) не трогаем: там все варианты должны оставаться доступными.
