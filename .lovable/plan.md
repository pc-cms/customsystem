# Брейк-лист: слоты до 05:40

Сейчас сетка брейк-листа во всех казино заканчивается на 04:40. Нужно продлить её на час — последняя колонка 05:40 (смена перекрывается до 06:00).

Контекст времени закрытия: Table Check — 05:00, Final — 06:00, поэтому сетка должна доходить до 05:40 включительно.

## Что изменится

- Временные колонки: 18:00 → 05:40 с шагом 20 минут.
- Добавляются колонки 05:00, 05:20, 05:40 (+3 колонки).
- Логика ролей, Sick/Late, автоскролл и подсчёт часов подхватят новые слоты автоматически (считаются от общего списка колонок).

## Технические детали

- Файл: `src/components/pit/BreaklistGrid.tsx`, функция `generateTimeSlots()` — цикл до 05:xx включительно.
- `isInWorkingHours` (18–07) уже покрывает новые слоты, менять не нужно.
- Изменение общее для всех казино (сетка не зависит от casino_id).
- Поднять версию в `package.json`.

## Примечание

Breaklist Lock по умолчанию 05:30 — после него сетка становится read-only, то есть слот 05:40 будет виден, но не редактируем. Скажите, если поднять Lock до 06:00 в настройках казино.
