# JP только в Day Closings

Сейчас JP вводится в Day Closings, но записывается в тот же журнал, что и Other Incomes (source = `jp`), поэтому каждая сумма видна дважды и путает.

## Что сделаем

1. **Other Incomes перестаёт показывать JP**
   - Из списка вкладки Other Incomes исключаются строки с источником JP (включая сторно-записи по JP).
   - Из выпадающего списка "Source" в диалоге Add Income убирается пункт JP — вручную его больше не завести.
   - Итоги/счётчики вкладки считаются уже без JP.

2. **Day Closings — единственное место JP**
   - Колонка JP (IN) и поле ввода остаются как есть (ввод/правка суммы за бизнес-день).
   - В строке дня добавляется подсказка со списком проведённых JP-записей (сумма, кошелёк, время, автор), чтобы не искать их в Other Incomes.

3. **Финансы не меняются**
   - JP по-прежнему проводится как доход в кошелёк, участвует в Variance, Wallets Breakdown (строка "JP (IN)") и в отчётах — меняется только место просмотра/ввода.

## Технические детали

- `src/hooks/use-other-incomes.ts`: добавить фильтр по источнику в `useOtherIncomes` (параметр `excludeSources`), список `OTHER_INCOME_SOURCES` для формы — без `jp` (лейбл `SOURCE_LABEL` для `jp` остаётся, чтобы старые записи корректно подписывались там, где нужны).
- `src/pages/office/OtherIncomesTab.tsx`: использовать хук с исключением `jp`.
- `src/pages/office/DayClosingsTab.tsx`: развёрнутая подсказка/поповер по JP-записям дня из уже загруженных данных.
- Данные в БД не мигрируются, схема не меняется.
