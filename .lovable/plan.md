# Casino Monthly Balance — раскрытия, панели деталей и страница расходов

## 1. Новая структура колонок

| Группа (шапка) | Свёрнуто | При клике раскрывается |
|---|---|---|
| Result | Result | Live, Table |
| Diff | Diff (= Chip Diff + Slots Diff) | Chip Diff, Slots Diff |
| Cage | Cage Casino, Transfer → Manager, Cage Manager, Transfer → Bank | без изменений |
| Bank | Bank TZS, Bank USD | без изменений |
| Office | + / − (бывшие IN / OUT), Expenses | без изменений |
| Balance | Money, Balance | без изменений |

- Группа `Flows` переименовывается в **Office**, колонки IN/OUT становятся **+** и **−**.
- Diff — новая группа: свёрнутая ячейка показывает сумму двух diff-ов.

## 2. Панели деталей (клик по ячейке → правая панель)

Клик по конкретной ячейке открывает боковую панель именно по этой ячейке и этому дню:

- **Chip Diff** — фишки закрытия live-кассы по номиналам: номинал, кол-во, miss, сумма TZS. Источник — `chip_snapshots` за дату (только фишки, не вся касса).
- **Slots Diff** — просто сумма TZS, без разбивки.
- **Cage Casino** — полная покупюрная разбивка на закрытие дня: TZS по номиналам, USD, EUR, GBP, KES, плюс безнал (Mobile Money, Airtel, карты и т. д.). Источник — `closing_count` смены live + closing-инвентарь Slots-кассы.
- **Transfer → Manager** — список переводов дня: сумма, откуда, куда, валюта/канал (TZS → TZS, Airtel → Airtel).
- **Cage Manager** — состояние manager/office сейфов на этот день (по каждому кошельку `office_safe` и резервам — баланс на конец дня).
- **Transfer → Bank** — список движений в банк со знаком (+ приход / − уход).
- **Money** — покупюрная фактическая сводка на момент закрытия дня.
- Остальные ячейки продолжают открывать общую панель дня.

Таблица остаётся нередактируемой, кроме **Bank TZS** и **Bank USD** — они по-прежнему заполняются вручную (или подтягиваются трансфером за конкретный день).

## 3. Balance = Variance

Колонка Balance повторяет формулу Variance из Office → Wallets: `Actual (money) − Expected`, стремится к нулю. Логика воспроизводится локально в хуке отчёта (без запроса RPC на каждый день), формула и тултип синхронизируются с формулировкой в Wallets.

## 4. Новая страница: Expenses by category

Клик по колонке/ячейке **Expenses** ведёт на отдельную страницу `/reports/expenses-matrix`:

- Слева — все категории расходов списком в алфавитном порядке, без сворачивания.
- Сверху — дни текущего месяца (колонки), переключатель месяца ‹ / ›.
- В ячейке — сумма расходов по категории за этот день (TZS), пустые дни — `·`.
- Строка Total снизу и колонка Total справа.
- Клик по ячейке открывает боковую панель со списком конкретных расходов (дата, сумма, описание, кошелёк).
- Липкая шапка и липкая первая колонка, тепловая заливка как в основном отчёте.
