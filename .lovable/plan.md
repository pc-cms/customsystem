# Expenses by Category — визуальная переработка матрицы

Цель: плотная, «дорогая» и читаемая таблица вместо блеклой сетки. Только презентационный слой (`src/pages/reports/ExpensesMatrix.tsx` + токены в `src/index.css`), формулы и данные не трогаем.

## Что меняем

### 1. Шапка
- Двухуровневая шапка дней: над числом — короткая буква дня недели (`Mo`, `Tu`… ), под ней число `01`, `02`. Выходные (Sa/Su) — отдельным фоновым оттенком колонки на всю высоту.
- Шапка: `bg-muted`, `font-bold`, `text-foreground`, `uppercase tracking-wide`, нижняя двойная граница, тень при скролле. Уже sticky — остаётся.

### 2. Колонка Category
- Sticky, фиксированная ширина, `font-semibold` для названия, группа — мелкой капителью приглушённым цветом.
- Строки одной группы бюджета (`salary`, `fixed`, `variable`…) получают тонкую цветную полосу слева (свой оттенок на группу) + разделитель между группами.

### 3. Колонки дней
- Чередование фона по дням (zebra по столбцам) для отслеживания взглядом по вертикали, поверх — heat-заливка суммы (3 ступени вместо нынешних бледных).
- Сегодняшний день — акцентная рамка колонки.
- Числа: `font-mono tabular-nums`, компактный формат (`12.5K` / `1.2M`) чтобы цифры влезали в ячейку; полное значение — в tooltip. Пустая ячейка — тонкая точка `·` очень приглушённая.
- Даты «короче»: только число (`01`), без месяца; ширина колонки дня фиксируется под 5 символов.

### 4. Итоги
- Колонка `Total` справа: более жирный шрифт, отдельный фон, двойная левая граница.
- Строка `Total` внизу (уже sticky): `bg-muted`, верхняя двойная граница, `font-bold`, крупнее на 1px, тень сверху.
- Пересечение Total×Total — самая контрастная ячейка (фон акцента).

### 5. Типографика и контраст
- Тело: `text-[11px]`, `leading-tight`, высота строки ~26px — больше дней помещается без горизонтального скролла.
- Значимые суммы — `text-foreground`, нулевые/пустые — `text-muted-foreground/50`. Никаких «серо-на-сером» для реальных чисел.

## Технические детали
- Новые семантические токены в `src/index.css` для оттенков групп бюджета и heat-ступеней (HSL), без хардкода цветов в компоненте.
- Компактный формат чисел — существующий `formatMoneyCompact` из `src/lib/format-money.ts`, полный — в `title`/tooltip.
- Всё остаётся на `SmartTable` (`headerClassName` / `cellClassName` / `footerRows`), новые обёртки не вводим.
- Поднять версию в `package.json`.
