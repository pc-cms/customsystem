# UI-обновление: Dashboard, профиль игрока, Player Statistics, Table Check

Семь отдельных задач, все — фронтенд/презентация.

## 1. Жирные сворачиваемые секции
- Dashboard: заголовки блоков («Day at a glance», «Tables Totals», «Floor Staff on Shift») делаем крупнее и жирнее, у каждого — стрелка свернуть/развернуть. Состояние запоминается локально.
- Страницы с вкладками (Pit, Player Profile, Finances/Office и т.п.): панель вкладок делаем жирнее и визуально плотнее, с той же логикой сворачивания секций внутри вкладки.
- Остальные страницы не трогаем.

## 2. Профиль игрока — блок Level
- Level поднимается выше в шапке профиля и рисуется крупнее (заметный бейдж рядом с именем/фото).

## 3. Профиль игрока — плитки
Ряд плиток за всё время (lifetime):
Drop · Result · Comps · Total и Visits · Avg drop · Avg session · Hold %.
Значения берём из уже существующих расчётов профиля (peak-NEP drop, result, comps, hold), просто переносим в новый компактный грид 4×2.

## 4. Профиль игрока — графики статистики
- График Drop и Result по визитам (столбики Drop + линия Result).
- График «ритма» — частота визитов по датам (сколько визитов/дроп по дням).

## 5. Dashboard — топ игроки за день
- Убираем блок «Floor Staff on Shift».
- Добавляем две колонки: Топ-10 по Drop и Топ-10 по Result за текущий бизнес-день, с порогом 1 000 000 (в списке только строки, проходящие порог). Клик по строке — переход в профиль игрока.

## 6. Player Tracking — липкая шапка
- Шапка таблицы Player Statistics фиксируется при прокрутке (включая горизонтальный скролл).

## 7. Zone → Game
- В Player Statistics, когда у игрока заполнена AVG ставка, колонка Zone показывается как **Game** со значением Live / Slots.
- Значение определяется по типу активности игрока за день (стол = Live, слоты = Slots). Если ставка не заполнена — поведение колонки Zone остаётся прежним.

## 8. Table Check — Drop + график
- В график аналитики Table Check (`TableAnalyticsChart`) добавляем показатель Drop наряду с текущими метриками.
- Такой же график добавляем в Player Statistics (по выбранному дню) с показателем Drop.

## Технические детали
- Файлы: `src/pages/Dashboard.tsx`, `src/pages/PlayerProfile.tsx`, `src/pages/PlayerStatistics.tsx`, `src/components/tables/TableAnalyticsChart.tsx`, `src/components/layout/AppSidebar.tsx` (стили вкладок), новый общий компонент сворачиваемой секции в `src/components/layout/`.
- Графики — recharts, цвета только через семантические токены.
- Топ-игроки считаются из уже загружаемых на дашборде транзакций + `player_day_drop_cache` (через `drop-source`), без новых таблиц.
- Числа — формат с пробелом, даты DD/MM/YYYY, UI на английском.
