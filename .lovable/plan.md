# График per-table result: два источника + плавная линия

## Что меняем

20-минутный график per-table result (18:00 → 06:00) использует два источника:

1. **Chips Check** — снимки фишек по столам (actual vs expected)
2. **Numbers / Table Tracker** — ручные записи

Сейчас в одном слоте побеждает тот, что записан позже, поэтому линия скачет между двумя разными смыслами, а в слотах без данных рвётся.

## Как будет работать

- Оба источника остаются.
- В одном временном слоте приоритет у **Chips Check** (это фактический пересчёт фишек); запись Numbers используется, только если чип-чека в этом слоте нет.
- Пустые слоты больше не рвут линию: точки соединяются между собой, промежуточные значения показываются как продолжение линии, а не как разрыв.
- Сглаживание линии остаётся мягким (monotone), маркеры точек — только там, где есть реальные данные, чтобы было видно, где факт, а где просто соединение.
- Цвета, подсказки, ось Y и сетка времени не меняются.
