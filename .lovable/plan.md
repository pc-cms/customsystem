План правок Breaklist:

1. Стартовая позиция при открытии (нет сохраненного скролла)
- Не скрывать слоты слева — все time slots смены остаются в DOM.
- Правило позиционирования: текущий 20-минутный слот должен быть 6-й видимой колонкой (5 слотов слева + текущий).
- Если слева от текущего слота нет 5 заполненных слотов (рано в смене) — скроллим к самому раннему заполненному слоту, чтобы видеть все заполненные слева + текущий (4, 3, 2 или 1 слот слева в зависимости от времени).
- Если в текущей смене вообще ничего не заполнено — скролл в начало (0).

2. Сохраненный скролл пользователя
- localStorage остается.
- Если есть сохраненная позиция — авто-позиционирование не применяется вообще.
- Авто-позиционирование срабатывает только при отсутствии сохраненной позиции (первый вход / новый день).

3. Заморозить колонки # C NAME S
- Сделать колонку `S` (Shift) sticky вместе с `#`, `C`, `NAME`. Горизонтальный скролл начинается с первого time slot.
- Убрать прозрачность фона у sticky-ячеек (`bg-card/95` → плотный `bg-card`, для зебры — плотный `bg-muted` вариант без альфы). Под скроллом time slots не должны просвечивать сквозь sticky-блок.
- Заголовок и тело: корректные `left` offsets для всех 4 sticky-колонок, плюс правый shadow/border на колонке `S`, чтобы визуально отделить замороженный блок от time slots.

4. Проверка
- При первом открытии в середине смены видно ровно 5 предыдущих + текущий слот.
- Рано в смене (например, заполнены только 2 слота) видно эти 2 + текущий, без пустого пространства слева.
- После ручного скролла позиция сохраняется и переоткрытие вкладки её восстанавливает.
- При горизонтальном скролле `# C NAME S` остаются на месте и полностью непрозрачны.
