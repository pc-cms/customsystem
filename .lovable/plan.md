# Attendance → Payroll (Mbeya) + экспорт в Excel

## Что показала проверка

Данные по Mbeya в базе есть и корректны: за август 331 запись по персоналу и 392 по дилерам, все привязаны к сотрудникам Mbeya, без «сирот». Функция месячной посещаемости для Mbeya возвращает 1674 строки, из них 722 с часами по 51 сотруднику — то есть экран Monthly Attendance получает данные.

Реальная причина «не подтягивается в Payroll»: пересчёт зарплатного периода берёт из посещаемости только три величины — часы в праздники, дни праздников и прогулы (код `A`). В Mbeya за август нет ни одного `A` и нет праздников, поэтому в периоде Mbeya (53 строки, статус draft) все поля из посещаемости равны нулю. Отработанные часы и дни, а также off days вообще нигде не переносятся — ни в Mbeya, ни в других филиалах.

Отдельно: деления на дневные и ночные смены больше нет — оплата идёт по часам, ночная надбавка убирается совсем.

## Что сделаем

1. **Убрать ночные смены из Payroll полностью** (все филиалы):
   - Колонки Night days / Night allowance hours / Night allowance убираются из таблицы периода и из расчёта: надбавка всегда 0, в брутто не входит.
   - Настройки `night_hours_per_day` и `night_rate_pct` убираются из Payroll · Settings.
   - Из банковских/печатных выгрузок ночная надбавка тоже уходит.
2. **Тянуть часы из обычного Attendance** (все филиалы):
   - Missing days — как сейчас (код `A`).
   - Отработанные часы и отработанные дни переносятся автоматически (новые справочные колонки в строке периода).
   - Off days / off days hours — переработка: дни сверх нормы (`working_days` из настроек) и часы этих дней; заполняются пересчётом, HR может поправить вручную.
3. **Кнопка «Export to Excel»** на странице Monthly Attendance — во всех филиалах. Файл: сетка «сотрудник × дни месяца» с кодами/часами, колонки итогов (Hours, Days worked, Leave, Holiday hours, OT), группировка по департаментам, шапка с названием казино и месяцем. Имя файла вида `Attendance_Mbeya_2026-08.xlsx`.
4. После правок — прогнать пересчёт периода Mbeya 08/2026 и проверить, что часы и дни появились.
