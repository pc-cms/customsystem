# Dashboard TV — визуальный редизайн (только фронтенд)

Только внешний вид. Формулы, запросы, источники данных, обновление и бизнес-логика не трогаются: компоненты продолжают получать те же `casinos / company / newPlayersCount / period` из `use-boss-dashboard` и `boss-display-metrics`. Структура блока казино (TABLES / SLOTS / TOTAL × DROP / RESULT / HOLD) сохраняется без изменений.

## 1. Шапка — строка KPI

TOTAL DROP / TOTAL RESULT / HOLD / HEAD COUNT / NEW PLAYERS остаются теми же пятью показателями.

- Компонент `Kpi` получает режим `center`: подпись по центру сверху (мельче, uppercase, tracking `0.24em`), значение по центру снизу — крупнее и жирнее, с явным вертикальным отступом.
- Колонки равной ширины (`grid-cols-5`, каждая `minmax(0,1fr)`).
- Между колонками — тонкие вертикальные золотые разделители: псевдо-элемент высотой ~58% строки, градиент прозрачный → `softGold` → прозрачный, низкая непрозрачность. Не на всю высоту, без разделителя после последней колонки.
- Чёрно-золотая айдентика сохраняется. DROP / HOLD / HEAD COUNT / NEW PLAYERS — единый тёплый ivory (`champagne`). TOTAL RESULT — по шкале интенсивности из п.3.

## 2. Городские темы

Новые акценты в `CITY_ACCENTS`: Arusha `#C86F3D`, Mwanza `#3A8FB7`, Dodoma `#C6923E`, Mbeya `#3D956B`.

- Акцент используется только для названия города, тонкой рамки блока (низкая непрозрачность) и пиктограммы. Метрики им не перекрашиваются.
- Новый файл с минималистичными line-art SVG-пиктограммами (24–40px, `opacity ~0.25`, `stroke: currentColor` в цвете города), подбираемыми по slug: гора (Arusha), волна/скала (Mwanza), акация/солнце (Dodoma), гора/лес (Mbeya). Для неизвестного slug — пиктограмма не рисуется.
- Никаких подзаголовков-регионов не добавляется. Существующая строка `Head N` остаётся на месте, только выравнивается по типографике.

## 3. Интенсивность RESULT

Утилита `resultTone(value)` в `tokens.ts`, единая для всех городов и для KPI шапки:

```text
|result| < 5 000 000        -> приглушённый  (зелёный #4E9E72 / красный #B9646C)
5M  <= |result| < 10M       -> средний        (#5FBF89 / #DC7480)
10M <= |result| < 20M       -> яркий          (#76DDA0 / #F4818C)
|result| >= 20M             -> максимальный   (#8CF7B4 / #FF97A0) + очень слабое свечение
result == 0 / нет данных    -> нейтральный ivory
```

Применяется одинаково к RESULT строк TABLES, SLOTS, TOTAL и к KPI TOTAL RESULT. Значения не пересчитываются — берётся уже готовое число. Легенда на экран не выводится.

## 4. Унификация таблицы

- Заголовки DROP / RESULT / HOLD и подписи TABLES / SLOTS / TOTAL — одинаковый шрифт, размер, вес и трекинг во всех городах (сейчас Black Gold рисует свои `Head`/`Line`, они приводятся к общим примитивам по стилю).
- DROP и HOLD — единый ivory во всех городах, моноширинные табличные цифры. Убирается городская подсветка/`glow` для этих колонок.
- Строка TOTAL сохраняет чуть более плотный фон и вес, но одинаковый для всех городов (приглушённое золото вместо цвета города).
- Разделители строк/колонок — тонкие приглушённо-золотые, не городские.
- Компактность и текущая плотность сохраняются: используются те же переменные `--tv-*` из `density.ts`, размеры шрифтов и высоты строк не увеличиваются.

## 5. Файлы

- `src/components/boss/tv/tokens.ts` — новые городские акценты, палитра интенсивности, `resultTone()`.
- `src/components/boss/tv/primitives.tsx` — `Kpi` (центрирование, разделение label/value), `KpiRow` с золотыми разделителями, `MetricRow` / `MetricsBlock` на новую окраску RESULT и унифицированные DROP/HOLD.
- `src/components/boss/tv/city-marks.tsx` — новый файл с SVG-пиктограммами городов.
- `src/components/boss/tv/black-gold.tsx`, `dark-gold.tsx`, `red-gold.tsx` — шапка KPI через `KpiRow`, пиктограмма и акцентная линия у названия города, унификация локальных `Head`/`Line`/`HeroStat`.

Никаких изменений в `src/pages/BossDashboard.tsx`-логике, хуках, БД, RPC и Edge-функциях.
