# Daily Balance Sheet — раскрытие групп и «Тоталы» категорий

## Проблема

1. Раскрытие работает только визуально у части групп: детальные колонки, у которых все значения за месяц = 0, продолжают скрываться фильтром «Hide empty» даже после клика по заголовку группы. Поэтому у групп Expenses / Transfers / Money / Balances после раскрытия ничего не появляется — только Incomes показывает детали.
2. У групп нет единой колонки-итога. Сейчас в свёрнутом виде группа показывает несколько «главных» колонок, а не один Total, который при раскрытии распадается на составляющие.

## Что делаем

### 1. Одна колонка-Total на каждую группу

В свёрнутом состоянии каждая группа = **одна** колонка «Total» с агрегатом по дню:

- Incomes → Live + Slots + Bar (= Result)
- Expenses → Expenses + Bank Expenses (со знаком минус)
- Transfers → Collection → Bank + Int. Transfer (+ Office In − Office Out)
- Money → Cage Cash + Office Safe + Bank Account
- Balances → Day Balance (ключевой показатель раздела)

Клик по заголовку группы разворачивает её в набор колонок-составляющих; колонка Total при этом остаётся первой в группе, чтобы было видно сходимость.

### 2. Явное раскрытие

- Заголовок группы всегда кликабелен и всегда показывает `+N` / `−` — даже если часть колонок пустая.
- «Hide empty» больше не применяется к колонкам раскрытой группы: раскрыл — видишь все составляющие, включая нулевые (нули рисуются как `·`).
- Кнопка «Expand all / Collapse all» работает по всем пяти группам.

### 3. Мелочи консистентности

- Тоталы групп участвуют в строках Total / Average / Week N и в панели деталей дня.
- Тепловая заливка применяется к колонкам-тоталам групп.
- Заморозка колонок: Date + Incomes Total.

## Техническая часть

- `src/pages/reports/DailyBalanceReport.tsx`: в `SECTIONS` для каждой секции добавляется вычисляемая колонка `total` (formula по строке), остальные колонки помечаются `detail: true`; `visibleMoneyCols` перестаёт применять `hideEmpty` к колонкам раскрытых секций; `groupHeader.expandable` = true для всех секций, `hiddenCount` считается от общего числа детальных колонок.
- Агрегаты недель/Total/Average пересчитываются по тем же формулам (не суммируются как готовые значения).
- Изменения только во фронтенде, запросы и БД не трогаем. Версия поднимается до 1.3.472.
