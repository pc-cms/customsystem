# Dashboard TV — редизайн шапки KPI

## Цель
Привести верхнюю панель Dashboard TV к виду, близкому к приложенному скриншоту: названия метрик и их значения отцентрированы, label/value визуально разделены, а колонки KPI разделены золотыми вертикальными полосами.

## Что меняем

### 1. Компонент `Kpi` (`src/components/boss/tv/primitives.tsx`)
- Добавить вариант отображения для шапки: `variant="header"` (или аналогичный флаг).
- Label и value выровнять по центру (`text-center`, `items-center`).
- Визуально разделить label и value:
  - label — на тонкой полупрозрачной подложке (`bg-white/5`–`bg-white/10`) с небольшим внутренним отступом;
  - value — ниже, на отдельной строке с увеличенным вертикальным расстоянием.
- Сохранить текущее поведение `Kpi` по умолчанию, чтобы не сломать другие места.

### 2. Black Gold / Dark Gold (`src/components/boss/tv/black-gold.tsx`, `src/components/boss/tv/dark-gold.tsx`)
- Обернуть 5 KPI в контейнер `grid-cols-5` с `divide-x` золотого цвета (`PREMIER.softGold` с прозрачностью ~30–40 %).
- Убрать обычный `gap`, заменив его на разделители.
- Каждую ячейку KPI выровнять по центру и дать горизонтальные отступы.
- Применить новый вариант `Kpi` (`variant="header"`).

### 3. Red Gold (`src/components/boss/tv/red-gold.tsx`)
- Применить аналогичные улучшения к `HeroStat` (центрирование label/value, визуальное разделение).
- Добавить золотые разделители между KPI в левом hero-блоке.

### 4. Проверка
- Убедиться, что при переключении Today/Monthly не появляются артефакты и метрики остаются читаемыми.
- Проверить preview в режиме TV.

### 5. Версия
- Повысить версию приложения до следующего патча (традиционно +1 к последней цифре).

## Исключено
- Изменение источников данных (metrics, ACE, day closings).
- Изменение логики Top Players или casino matrix.
- Изменение мобильной/не-TV версии Dashboard.
