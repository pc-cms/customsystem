# Касса и другие экраны видят всех отмеченных игроков

## Что проверено
- В базе все сейчас отмеченные игроки (Arusha 12, Dodoma 5, Mbeya 5, Mwanza 5) активны и не скрыты. Данные в порядке.
- Касса находит отмеченного игрока так: загружает **всю** базу игроков (2 782 человек, частями по 1000), затем оставляет только отмеченных. Если игрок выпал из этой большой загрузки (сортировка, старый кэш до обновления, только что зарегистрирован на другом компьютере), касса его не видит, хотя рецепция видит.
- Исправление сортировки уже сделано, но ещё не опубликовано, поэтому сотрудники работают со старой версией.

## Что сделаю
Уберу зависимость от общей базы: экраны, где нужны только игроки в казино, будут получать их напрямую из списка отметок (как рецепция), с фото, картой, категорией и тегами.
1. **Касса Live Game** (IN / OUT / список Guests) — игроки из открытых отметок этого казино.
2. **Pit → Active Players**, **Cashless**, **Tables** — то же для выбора игрока в казино.
3. Список отметок обновляется сразу при чек-ине (как сейчас) — новый игрок появляется в кассе без перезагрузки.
4. Поиск по всей базе (рецепция, статистика, профили) остаётся как есть.

## Проверка
После правки открою кассу в preview и сверю, что все отмеченные игроки каждого казино видны. Сотрудники получат исправление после публикации.

## Технически
- Новый хук `useCheckedInPlayers()` : `casino_visits` (date = бизнес-день, checked_out_at null) + join `players(*, player_cards, player_tags)`, ключ под realtime-инвалидацию `casino_visits` и `players`.
- `ActiveShiftView` использует его вместо `players.filter(checkedInIds)`; аналогично в `pit/ActivePlayers`, `Cashless`, `Tables`.
