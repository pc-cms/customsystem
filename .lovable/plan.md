# Collections: сортировка во вкладке + разбивка по категориям в Monthly Report

## Что делаем

Вкладка Office → Collections становится единым рабочим местом для всех collection-движений (старые записи из Expenses с группой Collections + новые signed-записи), а месячный отчёт показывает блок Collections с разбивкой по категориям, включая новые записи.

## 1. Интерфейс сортировки во вкладке Collections

- Кликабельные заголовки таблицы: Date, Direction, Category, Wallet, Amount. Клик — сортировка по возрастанию/убыванию, стрелка в заголовке.
- По умолчанию: Date по убыванию.
- Дополнительно к существующему фильтру: селекторы Category (все категории группы Collections) и Direction (All / IN / OUT), плюс Wallet.
- Группировка (переключатель "Flat / By category"): в режиме By category строки группируются по категории с подытогом IN, OUT и Net по каждой.
- Итоги сверху пересчитываются по текущей выборке фильтров.

## 2. Legacy-записи: смена знака/направления

- Старые строки (из Expenses, метка EXP) получают действие "Switch direction": переключение между Collected (OUT) и Returned (IN).
- Реализация без удаления истории: знак хранится в самой записи расхода (отрицательная сумма = возврат/IN), изменение проходит через тот же путь, что и обычное редактирование расхода, и логируется в аудите.
- Сумма, дата, категория и кошелёк legacy-записей остаются нередактируемыми в этой вкладке — меняется только направление.

## 3. Monthly Report: разбивка Collections по категориям

- Блок Collections в отчёте уже строится из расходов группы `collections` по категориям (Collection / CAPEX / Money Change). Новые записи из вкладки сейчас попадают только в общий Net.
- Изменение: новые записи (`fin_other_incomes`, source = `collection`) распределяются по своей категории и складываются с legacy-суммами внутри тех же строк категорий; записи без категории попадают в строку "Uncategorized".
- Итог группы = сумма строк категорий; общая цифра Collections в Cash Position не меняется по величине.
- Поведение закрытых месяцев не меняется: frozen Final Profit остаётся замороженным.

## Технические детали

- `src/pages/office/CollectionsTab.tsx`: локальное состояние сортировки/фильтров/группировки над уже объединённым списком (legacy expenses + fin_other_incomes), действие смены направления для legacy-строк.
- `src/hooks/use-fin-monthly-report.ts`: вместо единого `collectionEntriesNet` — агрегация collection-записей по `fin_category_id` и вливание в категории группы `collections` через `buildGroup`; итог группы пересчитывается из категорий.
- `src/pages/finances/FinancesMonthlyReportPage.tsx`: раздел Collections отображает полученные строки категорий (существующий фильтр ненулевых значений сохраняется).
- Изменений схемы БД не требуется. RPC, формулы прибыли и Cash Position не трогаем.
