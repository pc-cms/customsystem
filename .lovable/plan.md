# Фильтры в Transactions — только реально встречающиеся значения

Цель: в списках транзакций кассы кнопки-фильтры показывают только те значения, по которым за выбранный день действительно есть записи. Всё, чего нет, из фильтров исчезает полностью.

## Что сейчас

В истории кассы (Cage → History) фильтры жёстко зашиты списком:
- Cashless: всегда четыре провайдера (MTN, Tigo, Airtel, Halopesa), даже если за день не было ни одного платежа и даже если у филиала другой набор провайдеров;
- Cage transfers: всегда Live / Slots;
- Cash checks: всегда Live / Slots.

## Что сделаем

1. Список провайдеров в блоке Cashless строится из загруженных записей дня: только те провайдеры, по которым есть строки; названия — как они записаны в данных. Если записей нет, остаётся только кнопка ALL.
2. Кнопки Live / Slots в блоках Cage transfers и Cash checks показываются только если в данных дня есть записи соответствующего источника. Если источник один, кнопки выбора не нужны — остаётся ALL.
3. Если выбранный фильтр перестал существовать при смене дня, выбор автоматически сбрасывается на ALL, чтобы список не оказывался пустым без причины.

Ничего нового на экран не добавляем — только убираем пустые варианты. Логика подсчётов, отчёты и печать не меняются.
