# Аудит Attendance (все департаменты) + Master Attendance — только проверка, без исправлений

## Что уже видно в коде (предварительно, не подтверждено данными)

Часы из кода смены считаются в трёх независимых местах, и правила у них разные:

1. **Live Game (Pit) Attendance** — автозаполнение по коду роты: настроенные коды смен казино (с 01/09) → встроенные таблицы (Arusha / Dodoma / прочие); если код не найден — подставляется 9.
2. **Floor / Security / Office Attendance** — настроенные коды → встроенная staff-таблица; для старой сетки — всегда 8.
3. **Master (Monthly) Attendance** — считает часы в базе своей функцией (`get_monthly_attendance`), а не тем же кодом, что экраны выше. Ручные правки там хранятся в отдельной таблице.
4. Ручной ввод буквы (M, SW, N, T…) превращается в часы по жёстко зашитым числам (M=11, N=8…) — без учёта настроенных кодов казино и Arusha/Dodoma.

Отсюда вероятные рассинхроны: одна смена даёт разные часы на экране и в Master; код, которого нет в таблицах (новый/переименованный), остаётся без часов.

## Что проверю (только чтение, по всем 4 казино, сентябрь 2026)

1. Сравню по каждому сотруднику и дню: смена в роте → значение в Attendance → часы в Master Attendance. Выведу строки, где:
   - в роте рабочая смена, а в Attendance пусто или 0;
   - в Attendance буква/код, не превращённая в часы;
   - часы в Attendance ≠ часам в Master;
   - часы ≠ настроенному коду смены казино.
2. Найду коды смен, которые встречаются в ротах, но отсутствуют в настройках и встроенных таблицах.
3. Разберу функцию Master Attendance в базе и сверю её правила с правилами экранов.
4. Отдельно Management Attendance (слоты) — сверю с Master.
