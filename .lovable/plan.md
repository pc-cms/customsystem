# Вернуть печать после закрытия смены

## Проблема

- Live Game: после подтверждения менеджером страница «Close Shift» сразу уходит на /cage, потому что активная смена исчезает. Обязательное окно печати успевает только «мигнуть» и пропадает.
- Slots: после подтверждения открывается страница отчётов со ссылкой на печать, но окно печати там не всегда появляется (параметр печати теряется при переключении вкладки).
- На экранах «Manager Review» (Live и Slots) нет кнопки печати, поэтому вручную распечатать пакет из момента закрытия нельзя.

## Что делаем

1. Live Game: после успешного закрытия сначала показывается окно печати «Print Shift Closing Pack» и только после нажатия Print происходит переход на Cage. Автоматический уход со страницы блокируется, пока окно печати открыто.
2. Slots: после подтверждения открывается тот же обязательный пакет печати, гарантированно, независимо от вкладки на странице отчётов.
3. На экраны Manager Review (Live и Slots) добавляем кнопку **Print** — она открывает тот же самый пакет печати (по утверждённым цифрам смены). Больше ничего на этих экранах не меняем.
4. Ручная перепечать из Statistics/Reports остаётся как есть.
5. Печатается зафиксированный (неизменяемый) снимок отчёта — правила уже действующие, их не трогаем.

## Проверка

- Закрыть тестовую Live смену: окно печати появляется и не закрывается без печати; 4 листа, ориентация как утверждено.
- Закрыть тестовую Slots смену: то же самое.
- Кнопка Print в Manager Review открывает тот же пакет.
- Повторная печать из Reports работает.
- Поднять версию приложения. Публикация — только по отдельной команде.

## Технические детали

- `src/pages/cage/CloseShiftPage.tsx`: редирект `useEffect(!shift → nav("/cage"))` подавляется, пока `printShiftId` не null.
- Slots: в `ActiveSlotsShiftView.doApprove` вместо перехода на `/reports?tab=slots&print=` — открытие `PrintSlotsShiftDialog mandatory` на отдельном маршруте печати, чтобы размонтирование вью не убивало диалог; поддержку `?print=` в `SlotsHistoryReport` оставляем как запасной путь.
- Кнопка Print в Manager Review: `ReprintShiftDialog` (Live) и `PrintSlotsShiftDialog` (Slots), немодальный режим (`mandatory={false}`).
