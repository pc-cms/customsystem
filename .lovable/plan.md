# Boss TV Report: CAPEX отдельной строкой перед Collection

## Что изменится

В отчёте Company Report (Boss TV) строки пойдут в таком порядке:

```text
Estimated Expenses
Result (Table + Slot)
  Table Result
  Slot Result
CAPEX            ← отдельная строка, до Collection
Collection
```

Сами цифры, формулы, Balance и Expected Profit не меняются — только порядок строк. CAPEX остаётся приглушённой строкой и по-прежнему вычитается из Balance и Expected Profit.

## Почему строки не видно сейчас

Проверил все источники:

- код в проекте — строка CAPEX есть (сразу после Collection);
- опубликованная версия на всех доменах (casinosystem.app, www, mwanza, arusha, dodoma, mbeya, club, premier) — тоже отдаёт файл отчёта, где строка CAPEX есть.

Значит экран, который вы видите, показывает сохранённую в браузере старую копию отчёта: приложение хранит свои файлы локально, чтобы быстро открываться. После правки страницу нужно перезагрузить с очисткой кэша (Ctrl+F5, либо закрыть и заново открыть), и строка появится.
