# Автоперенос Estimated Expenses на новый месяц

## Причина
Автопереноса бюджета нет ни в одном казино. Для Arusha бюджет 30/06 сразу внесли на июль–декабрь через «Copy month». У Mbeya, Mwanza и Dodoma бюджет есть только на август–сентябрь, поэтому с октября Estimated Expenses у них = 0.

## Что сделаем
- Если на месяц бюджет не внесён, Estimated Expenses берутся из последнего месяца, где бюджет есть (для того же казино). Работает для всех казино.
- Как только на месяц вносят свой бюджет — используется он, перенос больше не нужен.
- В базе ничего не копируется: подстановка только при расчёте, поэтому правка сентября сразу видна в октябре, пока октябрь пустой.
- Касается Monthly Report / Dashboard (Estimated Expenses, Forecast, Balance, Bonus 5%).
- Страница Budget остаётся как есть (там пустой месяц — пустой), чтобы не путать с реально внесёнными цифрами.

## Техническая часть
- Миграция: в `boss_monthly_report` CTE `budget` заменить на выбор по каждому казино строк с `(year, month)` = максимальный `(year*100+month) <= _year*100+_month`, где есть записи в `fin_budget`. Остальная логика (FX на `v_to`) без изменений.
- Проверить остальные места, читающие `fin_budget` за месяц для Estimated (Budget vs Actual не трогаем).
- Проверка запросом: октябрь Mbeya/Mwanza/Dodoma = сумма сентября; Arusha без изменений.
