# Печатные пустые бланки (PDF)

Новая страница **Reports → Blanks**: список пустых бланков, каждый скачивается одним кликом в PDF. Никаких данных из системы — только шапка (казино, дата, смена — пустые линии) и пустая сетка для ручного заполнения.

## Бланки

1. **Shift Closing (столы)** — A4 альбом. Строки: столы казино (названия подставляются из справочника столов активного казино, цифры пустые); колонки: Opening chips, Fill, Credit, Drop, Closing chips, Result, Signature. Внизу строки Total и подписи (Pit Boss / Cashier / Manager).
2. **Cage Slots Closing** — A4 портрет. Секции: Opening cash, Slots IN / OUT, Cashless, Expenses, Collections, Closing cash по деноминациям (10k / 5k / 2k / 1k / coins), итог и подписи.
3. **Daily Balance Sheet** — A4 альбом. Сетка групп Incomes / Expenses / Transfers / Money / Balances с пустыми колонками дней и строкой Total.

Все бланки на английском, монолинейная сетка, тонкие рамки, крупные пустые ячейки под ручку, шапка с местом под казино/дату/подпись.

## Страница Blanks

- Маршрут `/reports/blanks`, пункт в сайдбаре рядом с Reports.
- Карточки по бланку: название, краткое описание, кнопка **Download PDF** (и опционально Print).
- Доступ по тому же правилу, что и `/reports`.

## Технически

- Генерация PDF на клиенте через `jspdf` + `jspdf-autotable` (добавить зависимости) — файл сразу скачивается, без окна печати и без серверной части.
- Модуль `src/lib/blanks/` : по файлу на бланк (`shift-closing-blank.ts`, `cage-slots-blank.ts`, `daily-balance-blank.ts`) + общий хелпер шапки/подвала/подписей.
- Названия столов для бланка №1 берутся из существующего хука таблиц активного казино; если столов нет — печатаются пустые пронумерованные строки.
- Ничего не сохраняется в БД, существующие пути печати (`printLiveGameReport`, PrintPortal) не трогаем.
- Поднять версию в `package.json` до 1.3.474.
