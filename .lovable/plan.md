# Table Check: почасовой Drop пишется сам + компактные Fill/Credit

## Что сейчас (проверено)

- Таблица `table_drop_tracker` пустая (0 строк): запись Drop сейчас происходит только внутри моста снимков фишек, поэтому если снимок фишек в этот час не сохраняли — часовая колонка Drop остаётся пустой.
- В `ChipCountPanel` колонки Fill и Credit показываются всегда, даже когда за смену не было ни одной операции — таблица становится шире без пользы.

## Что делаем

### 1. Drop заполняется каждый час сам

- Добавляем серверную запись: каждый час (по времени казино) фиксируется накопленный Drop по каждому столу «на момент часа» — прямо из кассовых транзакций, без зависимости от снимков фишек.
- Слоты те же, что в Table Check: 19:00 → 06:00 (06:00 = Final). Значение — сумма всех IN/BUY по столу за бизнес-день на момент записи (отменённые не считаются).
- Мост снимков фишек продолжает писать Drop как и раньше — записи не дублируются (обновление по ключу стол+дата+слот).
- Дополнительно: если текущий час ещё не записан, страница Table Check просит сервер зафиксировать его при открытии, чтобы колонка не пустовала до конца часа.
- Прошлые дни не восстанавливаются.

### 2. Fill/Credit — компактно и со знаками

- Колонки Fill и Credit на вкладке Chips скрыты, когда за смену нет ни одной такой операции.
- Если операции есть, появляется узкая сворачиваемая секция: по умолчанию одна колонка F/C с итогом, по клику раскрывается в две отдельные колонки Fill и Credit.
- Знаки: Fill всегда отображается со знаком «−» (красным), Credit со знаком «+» (зелёным). Расчёт результата не меняется.

## Технические детали

- Новая SQL-функция `record_table_drop_slot()` (SECURITY DEFINER): для каждого казино считает текущий бизнес-день и слот по Africa/Dar_es_Salaam, делает upsert в `table_drop_tracker` по `(table_id, date, time_slot)` суммой из `transactions` (`type in ('in','buy')`, `cancelled_at is null`, `created_at <= now()`).
- Cron-задание `record-table-drop-hourly` с расписанием `0 * * * *` (UTC) вызывает эту функцию; часы вне окна 19:00–06:00 EAT игнорируются внутри функции.
- Клиент: `src/pages/TableTracker.tsx` — вызов RPC при монтировании для текущего часа (только если сегодня) и инвалидация запроса `table-drop-tracker`.
- Клиент: `src/components/tables/ChipCountPanel.tsx` — условный рендер колонок Fill/Credit (`hasFillCredit`), состояние `fcExpanded`, форматирование со знаками через `cms-amount-negative` / `cms-amount-positive`.
- Версия приложения — **1.3.577**.
