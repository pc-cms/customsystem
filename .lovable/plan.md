# Daily Balance Sheet — чистая панель управления

Убираем перегруженную строку фильтров. Остаются только два переключателя, месяц уходит в шапку страницы.

## Что меняется

**Шапка страницы**
- Селектор месяца (`<input type="month">`) переезжает в правый слот `PageHeader`, рядом со счётчиком «N days · M columns».

**Строка фильтров (FilterBar)**
- Удаляется полностью вместе с кнопками: `Expand all / Collapse all`, `Short numbers`, `Weekly totals`.
- `Short numbers` больше не переключается — числа всегда в компактном формате (текущее поведение по умолчанию).
- `Weekly totals` фиксируется как включённые (недельные подытоги остаются).

**Кнопки в углах таблицы**
- Контейнер таблицы получает `relative`; поверх него — две плавающие компактные кнопки-иконки:
  - верхний правый угол: `Heatmap` (вкл/выкл тепловой карты);
  - верхний левый угол: `Columns` — показать/скрыть пустые столбцы (текущий `hideEmpty`).
- Кнопки полупрозрачные, поверх скролла (`absolute z-20`), с подсказкой (`title`), не перекрывают липкую колонку даты (смещение на несколько пикселей внутрь).

- `month` + `setMonth` передать в `PageHeader` через `children`.
- Оставшиеся `useSessionState`: `dbr-hide-empty`, `dbr-heatmap`, `dbr-month`.
