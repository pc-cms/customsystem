# Печать отчётов после закрытия смены — переделать флоу

## Что известно

- Окно печати не появляется ни в живой игре, ни в слотах, на кассовых компьютерах во всех городах.
- Механизм печати уже переписан на отдельные страницы печати (`/cage/print/:shiftId`, `/cage-slots/print/:shiftId`) в версии 1.3.746, но эта версия **не опубликована** — кассы работают на опубликованной 1.3.744, где печать открывалась поверх исчезающего экрана. Это самая вероятная причина «во всех городах».
- Дополнительно: сейчас страница печати рендерит только модальное окно поверх пустой страницы. Если окно по любой причине не открылось, человек видит пустоту и уходит дальше.

## Что делаем

1. **Убираем модалку из флоу закрытия.** Страницы печати становятся обычными полноэкранными страницами: шапка «Print Shift Closing Pack», предпросмотр всех четырёх листов, внизу две кнопки — **Print** и **Close without printing**. Никаких всплывающих окон, которые может «съесть» перерисовка.
2. **Страница печати всегда что-то показывает.** Пока отчёт подгружается — «Loading…» внутри страницы, кнопка Print неактивна. Никаких молчаливых переходов на открытие новой смены.
3. **Переход после подтверждения менеджера** (живая игра и слоты) ведёт на эту страницу; выйти с неё можно только двумя кнопками.
4. **Страховка** остаётся: если печать пропустили (перезагрузка, обрыв связи), при следующем входе в кассу страница печати откроется снова один раз.
5. **Кнопки Print в Manager Review и повторная печать из Reports/Statistics** — открывают ту же страницу печати, содержимое листов и расчёты не меняем.
6. **Проверка вживую** в браузере: закрыть тестовую смену в живой игре и в слотах, убедиться, что страница печати появляется и печатает 4 листа.
7. **Поднять версию и опубликовать** — без публикации кассы изменений не увидят.

## Проверка

- Живая игра: подтверждение менеджера → страница печати с предпросмотром → Print открывает системное окно печати → возврат в кассу.
- Слоты: то же самое.
- Manager Review: кнопка Print открывает тот же пакет.
- Reports/Statistics: повторная печать работает как раньше.
- После публикации — проверка на кассовом компьютере в одном из филиалов.

## Технические детали

- `src/pages/cage/PrintShiftPage.tsx` и `src/pages/cage-slots/PrintSlotsShiftPage.tsx` перестают монтировать `Dialog`. Печатное содержимое (`ReprintShiftDialog` / `PrintSlotsShiftDialog`) выносится в общие представления `ShiftPrintPack` / `SlotsPrintPack`: предпросмотр + `PrintPortal` + панель кнопок; диалоговые обёртки сохраняются только для немодальных вызовов из Manager Review и Reports.
- Ранние `return` при отсутствии `shiftId`/`casinoId` заменяются на состояние загрузки, чтобы страница не схлопывалась при гидрации `useAuth`.
- `printLiveGameReport` / слотовый аналог остаются без изменений (iframe + `PRINT_SHEET_CSS`).
- `pending-print` (localStorage) и редиректы в `Cage.tsx` / `CageSlots.tsx` сохраняются.
- Снимки отчётов (`report_snapshots`) и расчёты не трогаем.
