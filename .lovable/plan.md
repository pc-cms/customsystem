# Убрать лишнее с печатных отчётов и закрепить печать после закрытия

## Что меняем

1. Полностью убрать блок **Data Source** со всех четырёх печатных листов, включая `shift_close_id`, время закрытия, версию шаблона и время печати.
2. Оставить на листах только сами отчётные таблицы, итоги, подписи и стандартный нижний колонтитул. Другие поля и расчёты не менять.
3. После успешного подтверждения и закрытия смены менеджером открывать обязательное окно печати с кнопкой **Print**:
   - Live Game — окно появляется только после успешного закрытия;
   - Slots — окно появляется только после успешного закрытия;
   - окно не должно появляться до подтверждения менеджером;
   - ручная повторная печать из Statistics остаётся доступной.
4. Сохранить правило для всех филиалов: **все банковские и cashless-кошельки печатаются отдельными строками даже при нулевом значении**. Удалять или фильтровать нулевые строки нельзя.
5. Повторно прогнать печатную проверку для всех казино: четыре стабильных листа, правильная ориентация, без обрезания и без блока Data Source.
6. Поднять версию приложения после успешной проверки. Не публиковать без отдельной команды.

## Технические детали

- Удалить компонент и подключения `DataSource` из Slots, Live Game, Casino Chips Movement и Total Closing.
- Проверить оба post-close сценария и оставить обязательные окна печати только в обработчиках успешного закрытия.
- Списки банков и cashless строить из реестра кошельков филиала с добавлением найденных исторических ключей, без фильтрации по сумме.
- Обновить печатный тест, чтобы он запрещал возвращение блока Data Source и подтверждал наличие нулевых строк кошельков.
