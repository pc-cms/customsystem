## Цель
Сделать Reports → Daily Balance Sheet максимально читаемым: явные группы колонок, плитки сверху, нормальные итоги внизу.

## 1. Двухуровневая шапка (явное раскрытие)
- Добавить в `SmartTable` опциональный проп `groupHeader?: { label, colSpan, onToggle?, expanded?, hasDetail? }[]` — верхняя строка `<tr>` в `<thead>` с названиями разделов **INCOMES / EXPENSES / TRANSFERS / MONEY / BALANCES**, объединяющая колонки раздела.
- В ячейке группы: подпись + кнопка-шеврон `+N` (сколько скрытых деталей) — клик разворачивает/сворачивает раздел. Раздел без деталей — без кнопки.
- Нижняя строка шапки остаётся обычными заголовками колонок (сортировка сохраняется).
- Границы разделов (вертикальные линии) остаются, группа визуально выделена фоном `bg-muted/40`.
- Кнопка «Expand all / Collapse all» в FilterBar сохраняется.

## 2. Плитки сверху
Над FilterBar — сетка KPI (адаптив 2/3/6 колонок), по выбранному месяцу:
- Блок «Итоги месяца»: **Result** (Σ casino_result), **Expenses** (Σ expenses + bank_expenses), **Day Balance** (Σ day_balance).
- Блок «Деньги на последний день с данными»: **Cage Cash**, **Office Safe**, **Bank Account**.
- Формат чисел — как в таблице (учитывает переключатель Short numbers), знак через `cms-amount-positive/negative`.

## 3. Итоги внизу
- Заменить текущую «строку-ленту» на настоящий `<tfoot>` в `SmartTable` (новый проп `footerRows`), значения строго под своими колонками, выравнивание вправо, sticky bottom.
- Две строки: **TOTAL** (Σ по месяцу) и **AVERAGE** (среднее по дням, у которых есть данные).
- Первая колонка footer липкая, как и в теле таблицы.

## 4. Недельные итоги
- Между строками дней вставлять строку **Week N** после каждого воскресенья (по календарной неделе бизнес-даты): суммы по всем видимым колонкам, фон `bg-muted/50`, шрифт полужирный.
- Реализация: строки-агрегаты добавляются в массив данных с флагом `kind: "week"`; сортировка таблицы для этой страницы фиксируется по дате (сортировка по другим колонкам отключает недельные строки, чтобы не ломать смысл).

## 5. Тепловая заливка
- Для ключевых денежных колонок (Result, Day Total, Day Balance, Cash Desk) — лёгкий фон по знаку и относительной величине: зелёный/красный с альфой 0.06–0.18 через существующие токены (`--success`, `--destructive`). Пороговая шкала — от максимума абсолютного значения в колонке за месяц.
- Тумблер «Heatmap» в FilterBar (по умолчанию включён), состояние в `useSessionState`.

## 6. Клик по ячейке — детали дня
- Клик по строке (или по денежной ячейке) открывает боковую панель `Sheet` (на мобиле — `Drawer`) «Детали дня DD/MM/YYYY».
- Внутри: полный список всех колонок раздел-за-разделом с полными числами (без Short numbers), включая скрытые/пустые, плюс пометки источника (live / imported).
- Данные берутся из уже загруженной строки — новых запросов не требуется.

## 7. Заморозка колонок Date + Result
- Расширить `stickyFirstColumn` до `stickyColumns?: number` — липнут первые 2 колонки (Date и Result) c корректными `left` смещениями и тенью на границе.
