# Стиль двух таблиц: Expenses by Category + Casino Monthly Balance

Цель: плотные, контрастные и «дорогие» таблицы вместо блеклой сетки. Только презентационный слой (`src/pages/reports/ExpensesMatrix.tsx`, `src/pages/reports/DailyBalanceReport.tsx`, токены в `src/index.css`) — формулы и данные не трогаем.

## Общий визуальный язык (применяется к обеим таблицам)

### Шапка
- `bg-muted`, `font-bold`, `text-foreground`, `uppercase tracking-wide`, нижняя двойная граница, тень при скролле. Sticky сохраняется.
- Никаких дней недели — только число дня (`01`, `02`).

### Даты
- Колонка/заголовок даты — максимально короткая: в матрице расходов только число (`01`); в Casino Monthly Balance — `01/08` вместо полной даты, фиксированная узкая колонка.

### Числа
- **Только полные суммы, никаких сокращений** (`1 250 000`, а не `1.2M`). Разделитель разрядов — пробел.
- `font-mono tabular-nums`, `text-[11px]`, `whitespace-nowrap`; ширина колонок дней рассчитывается под самое длинное полное число месяца, чтобы цифры не переносились и не обрезались.
- Значимые суммы — `text-foreground`; нулевые/пустые — приглушённая точка `·`.
- Плюс/минус — через `cms-amount-positive` / `cms-amount-negative`.

### Границы и группы колонок
- Явные вертикальные разделители между колонками; двойная граница на стыке смысловых блоков.
- Каждый блок колонок получает свой мягкий фоновый оттенок (семантический токен), чтобы блоки читались как отдельные зоны.

### Итоги
- Правая колонка `Total` и нижняя строка `Total`: жирный шрифт, отдельный фон, двойная граница, тень. Пересечение Total×Total — самая контрастная ячейка.

## Expenses by Category
- Колонка Category: sticky, `font-semibold`, полная ширина под название.
- **Подпись группы бюджета из строки убирается** (группы будут переделаны позже) — остаётся только название категории.
- Heat-заливка ячеек: 3 внятные ступени вместо нынешних почти невидимых.
- Плотность: высота строки ~26px, `leading-tight`; горизонтальный скролл сохраняется, т.к. числа полные.

## Casino Monthly Balance
- Цветовое зонирование секций колонок: Fin Result / Casino result (Live Game, Slots, Bar, Tips) / Diff / Cage / Office / Expenses+Fees / Bank / Balances — каждая зона со своим оттенком фона и двойной границей на стыке.
- Sticky: колонка даты и Fin Result слева, строка итогов снизу.
- Строка незакрытого дня — приглушённая, но непрозрачная (sticky-колонки не просвечивают).
- Итоговая строка и KPI-плитки сверху согласованы по типографике с таблицей, суммы тоже полные.

## Технические детали
- Новые семантические токены в `src/index.css` (HSL) для зон колонок и heat-ступеней — без хардкода цветов в компонентах.
- Форматирование чисел — `formatMoneyFull` из `src/lib/format-money.ts` везде; `formatMoneyCompact` в этих двух таблицах не используем.
- Обе страницы остаются на `SmartTable` (`headerClassName` / `cellClassName` / `footerRows`), новых обёрток не вводим.
- Поднять версию в `package.json`.
