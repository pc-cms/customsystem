# Убрать слово «Cloud» из названий казино

## Что меняется

Названия казино в базе: `Arusha Cloud`, `Mwanza Cloud`, `Dodoma Cloud`, `Mbeya Cloud` → `Arusha`, `Mwanza`, `Dodoma`, `Mbeya`.

Это сразу отразится везде: переключатель казино, отчёты, печатные формы, дашборды, Wallets, Monthly Report — потому что интерфейс берёт название из базы.

## Будут ли проблемы

Нет. Проверено:
- Идентификация казино везде идёт по `id` и `slug` (`arusha`, `mwanza`, ...), а не по названию. Слуги и коды (ARU/MWZ/DOD/MBY) не трогаем.
- Поддомены, права доступа, синхронизация и лицензии завязаны на `slug`/`id` — не затрагиваются.
- Единственное место, где сравнение шло по названию — старые миграции (уже выполненные), на текущую работу не влияют.
- Импорт Excel сопоставляет казино нечётко по имени — короткое имя работает даже лучше.

## Технические шаги

1. Миграция: `UPDATE public.casinos SET name = regexp_replace(name, '\s*Cloud$', '')`.
2. `src/pages/Login.tsx` — убрать «Cloud» из захардкоженной карты названий по поддоменам.
3. `src/pages/finances/FinancesMonthlyReportPage.tsx` — убрать теперь лишний хак `name.replace(/\s*Cloud$/, "")`.
4. Поднять версию в `package.json`.
