## Что делаю

1. **Автозаполнение при закрытии дня (в базе, без открытия экранов).** Когда бизнес-день закрыт (вручную в Day Closings или автоматически в 07:00), для каждого сотрудника этого казино со сменой в Rota в Attendance проставляются часы по коду смены **этого казино и этого отдела**.
   - Заполняются только пустые клетки. Ручные значения (часы, A, S, SP, L, 8L и т.п.) никогда не перезаписываются.
   - Нерабочие коды (L, O) и неизвестные коды не заполняются.
   - Live Game → табель дилеров; остальные отделы → табель персонала.
   - Отделы без своего набора кодов (Bar, Cash Desk, Housekeeper в Dodoma и др.) берут коды той группы, в которой они показаны на экране Rota (Floor / Security / Office) — так же, как экран сейчас.
2. **Заполнение пропусков сентября** (01–28/09, только закрытые дни, только пустые клетки) по тем же правилам — Arusha, Dodoma, Mbeya.
3. Экранное автозаполнение оставляю как есть (оно тоже заполняет только пустое, конфликта не будет).
4. После — повторная сверка: пропусков 0, Master Attendance показывает те же часы.

Management Attendance не трогаю (у менеджеров отдельный список и автоподсчёт уже работает).

## Технические детали

- Новая функция `attendance_autofill_day(casino_id, date)` (SECURITY DEFINER): join `pit_rota`/`staff_rota` → `employees` → `shift_codes(casino_id, department-group, code, is_working)`; `INSERT ... ON CONFLICT DO NOTHING` в `dealer_attendance`/`staff_attendance` (плюс пропуск строк с непустым value).
- Маппинг department сотрудника → группа кодов (pit/floor/security/office) — тот же, что использует Staff (`src/lib/staff-dictionaries.ts`), продублирован в SQL.
- Триггер AFTER INSERT/UPDATE на `business_day_closures` вызывает функцию.
- Бэкфилл сентября — разовый вызов функции по закрытым дням.
- Фоновых расписаний не добавляю.
