# Единый вид таблиц в Office / Statistics + чистка заголовков

## Цель
1. Все таблицы в Office и Statistics выглядят как Live Game: на всю ширину, sticky-шапка, сортировка по клику, строка тоталов внизу, без внутренней обрезки по высоте.
2. Внутри вкладок Finance (Office) убраны текстовые шапки страниц и подписи секций — навигация уже даёт контекст.

## 1. Единый табличный стандарт

Эталон — `DataTable` / `SmartTable` (шапка sticky, зебра, mono-числа, тип колонки задаёт ширину/выравнивание).

Правила, применяемые ко всем перечисленным экранам:
- Таблица занимает 100% ширины контейнера; горизонтальный скролл только когда колонок реально больше, чем экран.
- Никаких `max-h-[65vh]` / `max-h-[70vh]` / `calc(100vh - …)` — контейнер убирается, страница скроллится целиком, шапка остаётся прилипшей.
- Сортировка по клику доступна на всех колонках (включая дневные сетки Bank / Cashless / Day Closings / Rates / Miss Chips). Сортировка по умолчанию — как сейчас (дата по убыванию).
- Итоговая строка (`Totals` / `Month sum`) остаётся прилипшей к низу таблицы и не участвует в сортировке.

## 2. Убрать шапки и подписи секций в Finance-вкладках
- Удалить `PageHeader` внутри вкладок: Import Statement, Inter-Casino (и любых других, где он остался). Кнопки-действия из шапки переносятся в общий тулбар через `OfficeActions`, чтобы ничего не потерялось.
- Убрать текстовые заголовки секций: «Bank · daily movements», «Cashless · daily movements», «Wallets», «Breakdown (Expected)», «Grand Total (Wallets)», «Transactions · N», «1. Bank account & file», «2. Import batches», «3. Review — …».
- Там, где подпись несёт смысл (например счётчик строк или шаг импорта), оставляем компактный признак внутри самой таблицы/кнопки, а не отдельный текстовый блок.
- Верхнее меню вкладок и период-пикер остаются без изменений.

## Технические детали
- Никакой бизнес-логики, запросов и формул не трогаем — только презентационный слой.
- Сортировка реализуется через существующий `SmartTable` (`sortValue` на колонках); для дневных сеток добавляется `sortValue` на дату и на каждую числовую колонку.
- Строка тоталов остаётся вне сортируемого массива (footer-строка SmartTable).
- Проверка: сборка + визуальный прогон вкладок Office и Statistics в превью.
- Патч-бамп версии приложения.
