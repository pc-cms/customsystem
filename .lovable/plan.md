# Убрать слово «Cloud» из названий казино

## Что меняется

Названия в базе: `Arusha Cloud` → `Arusha`, `Mwanza Cloud` → `Mwanza`, `Dodoma Cloud` → `Dodoma`, `Mbeya Cloud` → `Mbeya`.

Отразится сразу везде, где интерфейс берёт название из базы: переключатель казино, дашборды, Wallets, Monthly Report, печатные отчёты, заголовки.

## Глубокая проверка — проблем не будет

Проверено по коду и по базе:

- **Идентификация казино** везде идёт по `id` (UUID) и `slug` (`arusha`/`mwanza`/`dodoma`/`mbeya`). Названием никто не «ищет» казино.
- **Поддомены и роутинг** (`casino-context`) — только по `slug`, не по `name`.
- **Права доступа / RLS / user_casino_access** — по `casino_id`. Ни одна политика не сравнивает название.
- **Функции и триггеры базы** — проверил все функции схемы `public`: ни одна не содержит строку вида `'... Cloud'` и не сравнивает `casinos.name` с текстом.
- **Edge-функции** (installer, branding, club-wallet, smoke-test) — название используется только для отображения.
- **Excel-импорт финансов** — нечёткое сопоставление по имени касается категорий расходов, не казино; альясы казино не завязаны.
- **Синхронизация / фleet / лицензии / cutover** — работают по `slug`, `node_identity` и `casino_id`. Слово «Cloud» там означает режим работы (cloud/local), а не название казино — его не трогаем.
- **Уникальных ограничений и внешних ключей по `casinos.name` нет** — переименование безопасно.
- **Историчные данные** (транзакции, смены, отчёты) хранят `casino_id`, а не текст — старые отчёты не «поедут».
- **Уже есть поле `short_name`** (`Arusha`, `Mwanza`, ...) — после переименования `name` и `short_name` совпадут, конфликта нет.
- Единственные упоминания «X Cloud» в коде — карта названий на странице входа и косметический хак в Monthly Report; оба правим.

Единственный видимый эффект: на экране входа и в отчётах будет короткое название. Откат — одна обратная миграция.

## Технические шаги

1. Обновление данных: `UPDATE public.casinos SET name = regexp_replace(name, '\s*Cloud$', '')` (при желании — синхронизировать `meta_title`, они и так уже «Premier Arusha …», их не трогаем).
2. `src/pages/Login.tsx` — убрать «Cloud» из карты названий по поддоменам.
3. `src/pages/finances/FinancesMonthlyReportPage.tsx` — убрать теперь лишний `name.replace(/\s*Cloud$/, "")`.
4. Поднять версию в `package.json`.
