# Dashboard TV — имя менеджера текущей смены под названием локации

## Цель
В Boss → Dashboard TV в режиме Live (Today) под названием каждого казино показывать имя менеджера, который сейчас на смене, по Management Rota. Monthly-режим и Company Report не трогаем.

## Правила выбора менеджера
- Источник: `management_rota` + `management_slots` (block = "casino", casino_id = локация) + `management_people` (имя), за сегодняшнюю дату EAT.
- Смены и окна (как в роте): D = 10:00–18:00, M = 13:00–21:00, N = 18:00–06:00 (через полночь).
- Текущая смена = смена, чьё окно содержит текущее время EAT; при пересечении окон (13:00–18:00 — D и M; 18:00–21:00 — M и N) берём смену, которая началась позже (M вместо D, N вместо M).
- Если на ту же смену назначено несколько человек — показываем всех через « · ».
- Если у человека на сегодня в `management_attendance` стоит отметка A / L / S — он не считается на смене.
- Если никого нет — показываем «—».

## Что делаем

### 1. Хук дежурных менеджеров
- Новый `src/hooks/use-duty-managers.ts`: запрос `management_slots` (block="casino", текущий месяц), `management_rota` (сегодня EAT), `management_attendance` (сегодня), `management_people`. Возвращает `Record<casinoId, string>` — имя(ена) менеджера текущей смены. `staleTime` 60s, refetch раз в минуту (смена может переключиться на границе часа).

### 2. Прокинуть в TV
- `src/components/boss/tv/types.ts`: в `TvCasino` добавить `dutyManager: string | null`.
- `src/pages/BossDashboard.tsx`: при сборке `tvCasinos` подставить `dutyManager` из хука (только для Live; в Monthly оставить null).

### 3. Отображение (только Live-стили)
- В `live-stage.tsx`, `dark-gold.tsx`, `black-gold.tsx`, `red-gold.tsx` (и `mobile-live-stage.tsx`, если есть) под названием города, рядом/под строкой «Head N», вывести строку с именем менеджера тем же мелким стилем (uppercase, приглушённый), например `MGR · ANNA`. Только когда `period === "today"` и `dutyManager` задан; иначе «—».
- Метрики, формулы и источники данных не меняются — только отображение.

## Проверка
- Typecheck + сборка.
- Playwright: Live-режим, под каждым казино видно имя менеджера текущей смены; проверить пересечение смен (13:00–18:00 показывает M).
- Monthly-режим без изменений.
- Публикация не выполняется.
