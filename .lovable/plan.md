# Импорт роты Pit (Arusha) на август 2026 из листа "August"

## Что известно из файла
- Лист `August` — рота дилеров и питов Arusha.
- Совпало 23 сотрудника Pit Arusha по имени; 3 строки без совпадений — новые люди (**New 1**, **New 2**, **New 3**, Trainee).
- В ячейках указаны часы (11 или 10), тип смены задаётся цветом заливки:
  - 11ч, зелёный → **M** (Middle, 18:00–05:00, 11ч)
  - 11ч, синий → **SW** (Swing, 19:00–06:00, 11ч)
  - 10ч, голубой → **N** (Night, 20:00–06:00, 10ч)
  - пустая ячейка → **O** (Off)
- Zuhura Omari уже выведена из Pit в Office со сменами **T** (Training) — в импорт не входит.

1. Код смены `SW`
   - Значение `SW` уже добавлено в enum `shift_type` в базе.
   - Добавить `SW` в сетку смен Pit в интерфейсе: список кодов, легенда, подсказка времени (19:00), цвет (синий, отдельно от `N`).

2. Прогноз часов (Σh) для Pit Arusha
   - В `src/lib/shift-hours.ts` завести отдельную сетку для Pit Arusha: `M = 11`, `SW = 11`, `N = 10`, `L/O = 0`.
   - Остальные казино сохраняют текущую логику (M/EM = 11, N/EN/G = 8, прочие = 9).

3. Новые сотрудники
   - Создать в Arusha трёх сотрудников Pit: New 1, New 2, New 3, категория Trainee, статус active.

4. Массовый импорт роты

   - Перезаписать `pit_rota` для 26 сотрудников за 01–31.08.2026 согласно файлу (полная замена, а не дополнение).
