# Statistics → Tables в формате вашего файла (Drop / Result / % по каждому столу)

## Чем сейчас отличается от вашего файла

| Что | Ваш файл | Сейчас в CMS |
|---|---|---|
| По каждому столу в день | 3 колонки: **D, R, %** | Result, Drop мелкой строкой (если включена кнопка Drop), **% нет** |
| Итог периода по каждому столу | D, R, % | только Result (+ Drop мелко) |
| Итоги по видам игр (AR, NIU NIU, PK, BJ) | Drop, Result, **Hold** | Result (+ Drop мелко), **Hold нет** |
| Общий итог (Live) | D, R, % в день и за период | Drop и Result, **% нет** |
| Средний Drop и Result в день | есть | **нет** |
| Колонки Month и Day (день недели) | есть | только дата |
| Excel | в этом же формате | плоский список, без итогов по играм сверху |

Итог: цифры Drop и Result в CMS уже есть, не хватает процентов (Hold), средних значений и раскладки «3 колонки на стол».

## Что сделаю

**Шапка (как строки 2–5 файла):**
- Плитки по видам игр: Roulette, Poker, Blackjack, Niu Niu, Baccarat, Club, Other. В каждой Drop, Result и Hold %.
- Плитка **Total Live**: Drop, Result, Hold %.
- **Average Drop / Average Result** за день (делим на число дней с игрой).

**Таблица:**
- Колонки: Date, Month, Day, затем по каждому столу **D | R | %**, затем итог каждой группы игр **D | R | %**, в конце **Live D | R | %**.
- Строка **TOTAL** за период по каждому столу и группе: D, R, %.
- % = Result / Drop. Если Drop = 0, ставим «·».
- Отрицательные значения красные, положительные зелёные, как сейчас.
- Остаются фильтры групп и столов, сортировка и выбор периода. Кнопка **Drop** превращается в **Drop & %**: можно скрыть D и %, оставить только R.

**Excel:** выгрузка в той же раскладке, что ваш файл: шапка с периодом, итоги по играм сверху, затем дни с D/R/% по столам.

## Правила расчёта (не меняются)
- Drop стола = сумма IN по столу (как сейчас).
- Total Live Drop = Drop казино из кэша (как сейчас). Поэтому сумма Drop столов может немного отличаться от Total — так задумано.
- Result — из закрытых результатов столов, Fill и Credit уже внутри.
