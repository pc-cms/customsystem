# Arusha: игрок FRANK JOHN не виден Pit и Manager

## Причина (проверено в базе)
- FRANK JOHN создан 16/11 автоматически из ACE и помечен как «тестовый игрок ACE».
- Такие игроки видны в общем списке только Super Admin. Поэтому Pit и Manager его не видят на странице игроков (Player Statistics и другие списки).
- Рецепция и касса находят его через список отмеченных на входе: там эта пометка не учитывается.
- При этом это живой игрок: у него 4 визита и 23 транзакции.
- Та же ситуация у других игроков с визитами: Arusha — 62, Mbeya — 18, Mwanza — 1.

## Варианты (выберите один)
**A. Показывать всем ролям ACE-игроков, у которых есть визиты.** Пометка остаётся, данные не меняются. Игроки ACE без визитов по-прежнему видны только Super Admin. Это правка только в отображении.

**B. Снять пометку ACE с этих 81 игрока.** Это изменение данных. Они станут обычными игроками навсегда, у новых таких игроков проблема повторится.

Рекомендую A: данные не меняются, и проблема решается и для будущих игроков.

## Что будет после
Pit и Manager увидят FRANK JOHN и остальных 80 игроков с визитами во всех списках игроков. Финансовые цифры не меняются.

## Технические детали (для A)
- `src/hooks/use-players.ts` → `usePlayers`: для не-super_admin вместо `is_ace_auto = false` фильтр `is_ace_auto = false OR` у игрока есть визит. Реализация: дополнительно загрузить id игроков из `casino_visits`, у которых `is_ace_auto`, и добавить их в список, либо `or(...)` через view. Без migration.
- Ключ кэша остаётся прежним. Проверка: FRANK JOHN появляется под ролью Pit/Manager.
