# Statistics → Graphics: переработка годового графика

Цель: сделать график читаемым и информативным — HeadCount не должен доминировать, линии плавные, легко сравнивать показатели.

## Что меняется

1. **HeadCount уходит на второй план**
   - Рисуется не линией, а полупрозрачными столбиками (bars) на фоне, по правой оси.
   - Правая ось получает свой домен (0 → max×2), поэтому столбики занимают максимум половину высоты и не перекрывают денежные линии.
   - Приглушённый серо-синий цвет вместо красного (красный сейчас читается как «ошибка»).

2. **Деньги — четыре плавные линии**
   - `type="natural"` вместо `monotone` + `strokeWidth 2.5` для мягкой кривой.
   - Drop Table получает лёгкую заливку-градиент (area) как опорный объём, Result — чистые линии поверх.
   - Точки показываются только при наведении (`dot={false}`, крупный `activeDot`), линия перестаёт быть «зубчатой».

3. **Интерактивная легенда**
   - Клик по элементу легенды включает/выключает серию, чтобы можно было смотреть, например, только Slots.
   - Активное/выключенное состояние подсвечивается.

4. **Тултип**
   - Кастомный: месяц в шапке, значения в столбик с цветными маркерами, деньги форматируются пробелами, HeadCount — целое число, плюс строка Total Drop / Total Result.

5. **Прочее**
   - Месяцы будущего (после текущего) не рисуются пустыми нулями — линия обрывается на текущем месяце.
   - Высота 480px, увеличенные отступы, сетка светлее.
   - Плитки итогов снизу остаются, но становятся кликабельными переключателями серий (та же логика, что и легенда).

## Технические детали

Файл: `src/components/reports/YearlyGraphicsReport.tsx` (только фронтенд, запросы данных не меняются).
- `ComposedChart`: `Bar` (headCount, yAxisId right, barSize ~18, opacity .25) + `Area` (dropTable) + `Line`×3.
- `YAxis right`: `domain={[0, (max) => max * 2]}`, `allowDecimals={false}`.
- Локальный `useState<Set<string>>` для скрытых серий, `hide` prop на каждой серии.
- Версия приложения повышается до **1.3.561**.
