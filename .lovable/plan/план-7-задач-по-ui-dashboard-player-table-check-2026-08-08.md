# План: 7 задач по UI (Dashboard, Player, Table Check)

## 1. Жирное меню + сворачиваемые группы
Пункты верхнего уровня в боковом меню (Dashboard и все разделы с вложенными вкладками) — полужирный шрифт. Группы с вложениями получают сворачивание/разворачивание с сохранением состояния (группа с активным маршрутом всегда раскрыта).

## 2. Блок игрока: Level выше и крупнее
В карточке игрока (`PlayerProfile.tsx`) уровень/категория поднимается в верхнюю строку рядом с именем и увеличивается (крупный бейдж с цветом тира).

## 3. Плитки в профиле игрока
Две строки по четыре плитки:
- Строка 1: Drop / Result / Comps / Total
- Строка 2: Visits / Avg Drop / Avg Session / Hold %
Значения — за выбранный период профиля (текущий фильтр горизонта: today / 7d / 30d / all).

## 4. Статистика игрока: графики
В `PlayerStatistics.tsx` добавляются:
- Комбинированный график Drop и Result по визитам (бары Drop + линия Result).
- «Ритм» — частота визитов по дням недели / интервалы между визитами.

## 5. Dashboard: топ игроков дня, убрать график персонала
- Новый блок «Top players today»: до 10 игроков за текущий бизнес-день с Drop ≥ 1 000 000 либо значимым Result, сортировка по Drop.
- Удаляется график по персоналу.

## 6. Липкая шапка Player Tracking
Шапка таблицы Player Tracking фиксируется при вертикальной прокрутке (как в Incidents).

## 7. Zone из ставки + Table Check: DROP и график
- Если у игрока заполнена средняя ставка, Zone проставляется автоматически по значению ставки (источник = Game), без ручного ввода.
- В Table Check добавляется колонка/плитка DROP по столу и мини-график динамики по слотам времени.

## Технические детали
- Затрагиваются: `src/components/app-sidebar` (меню), `src/pages/PlayerProfile.tsx`, `src/pages/PlayerStatistics.tsx`, `src/pages/Dashboard.tsx`, `src/pages/TableTracker.tsx` и связанные хуки.
- Drop берётся из единого источника `src/lib/drop-source.ts` (per-table = Σ IN транзакций, Total = `player_day_drop_cache`).
- Графики — на recharts, форматирование чисел через пробел-разделитель, даты `DD/MM/YYYY`.
- Логика расчётов не меняется, работа только в презентационном слое, кроме автоподстановки Zone (пункт 7), где добавляется маппинг ставка → зона.

## Порядок
Задачи независимы и делаются по одной: 1 → 2 → 3 → 4 → 5 → 6 → 7. Можно начать с любой.
