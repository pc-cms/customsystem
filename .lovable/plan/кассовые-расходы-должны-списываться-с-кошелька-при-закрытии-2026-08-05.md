# Кассовые расходы должны списываться с кошелька при закрытии дня

## Диагностика (проверено на данных Мванзы, 01–05/08/2026)

- Variance = **+2 496 853** (Actual больше Expected).
- Расходы за август: office **16 516 500** (14 шт.) — у всех есть движение по кошельку; cage/live_game **2 849 500** (35 шт.) — **ни у одного нет движения по кошельку**.
- Все дни 01–04/08 закрыты, поэтому Expected эти 2 849 500 уже вычитает — правильно, как вы и говорите.
- Но Actual их не вычитает: деньги из кошелька никто не снял. Отсюда перекос: 2 849 500 − 352 647 (прочий шум) = **2 496 853** — ровно текущая Variance.

Вывод: формула Expected верна, менять её не нужно. Ломается сторона Actual — кассовый расход не превращается в движение по кошельку.

## Что делаем

Правило по срокам:
- **Офисный расход** — влияет на кошелёк сразу в момент одобрения (так работает и сейчас, не меняем).
- **Кассовый расход (Live / Slots)** — списывается с кошелька на следующий день, в момент закрытия бизнес-дня (07:05 EAT), вместе с результатом дня.

При закрытии бизнес-дня система автоматически списывает с кошелька все одобренные кассовые расходы этого дня. Один расход — одно движение, повторно не создаётся.


Кошелёк-источник: основной TZS-кошелёк казино (тот же, куда идут JP и Other Incomes). Расход в валюте списывается по курсу дня в TZS-эквиваленте.
