# Table Check: колонка Final должна приходить из закрытия смены

## Что не так (проверено)

- В таблице Table Check колонка **Final** — это слот `06:00`.
- Автозапись из закрытия (триггер по снимкам фишек столов) кладёт значение в слот **`05:00`**, а не в `06:00`.
- В базе за последние 20 бизнес-дней нет ни одной записи со слотом `06:00` — колонка Final физически всегда пустая, а её значение видно в соседней колонке `05:00`.
- Дополнительно: то, что пишет триггер, — это только дельта по фишкам (факт − ожидание), а не итог закрытия стола (Drop + Credit − Fill ± Δфишек), который печатается в отчёте закрытия смены.

## Что делаем

1. **Final берём из закрытия смены.** В колонку Final (`06:00`) пишем per-table результат закрытия — тот же, что используется в Shift Closing / Dashboard (`compute_shift_table_results`), а не «сырую» дельту фишек. Запись происходит в момент закрытия смены столов и обновляется при редактировании/перепечатке закрытия.
2. **Правим слот у триггера-моста.** Промежуточные пересчёты фишек продолжают падать в свои часовые слоты (19:00–04:00), но «финальное окно» (04:50–07:00) больше не занимает слот `05:00` — оно уходит в Final. Слот `05:00` остаётся для обычного пересчёта в 05:00.
3. **Ручной ввод сохраняется.** Если менеджер вручную вписал значение в Final, повторное закрытие/пересчёт его перезапишет актуальным итогом закрытия (как и сейчас у других авто-слотов).
4. **Исторические дни.** Переносим уже записанные «финальные» значения из `05:00` в `06:00` за прошлые бизнес-дни, чтобы колонка Final не была пустой в архиве. По желанию можно ограничить период — скажите, если хотите перенести только, например, с 01/08.

## Технические детали

- Правка функции `bridge_chip_snapshot_to_tracker()`: `target_h := 5` → слот `06:00` для финального окна.
- Новый серверный шаг при закрытии смены столов: upsert в `table_tracker` (slot `06:00`) значений из `compute_shift_table_results` для каждого стола смены; тот же вызов при пересохранении закрытия (Edit/Reprint).
- Разовая миграция данных: перенос строк `time_slot='05:00'`, попавших туда из финального окна, в `06:00`.
- Фронтенд `src/pages/TableTracker.tsx` менять не нужно — колонка Final уже отрисована, изменится только источник данных.
