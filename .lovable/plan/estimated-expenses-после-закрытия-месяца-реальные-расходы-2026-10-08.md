# Estimated Expenses после закрытия месяца = реальные расходы

## Что проверено
- **Monthly Report по городам**: правило уже работает. Пока месяц открыт, считается бюджет. После закрытия месяца считаются реальные расходы (Actual Expenses), а также внеплановые расходы, которые не попали в Actual.
- **Dashboard / Boss TV (Monthly Report)**: правило НЕ работает. Строка Estimated Expenses всегда берёт бюджет (или бюджет прошлого месяца), даже если месяц закрыт. От неё зависят Expected Profit, Balance и Bonus 5%.
- Закрыты: сентябрь во всех 4 казино, август в Mbeya, июль в Arusha.

## Что сделаем
- Dashboard / Boss TV: для казино, у которого месяц закрыт, Estimated Expenses = реальные расходы за месяц. Сумма берётся по тому же правилу, что в Monthly Report по городам, поэтому цифры совпадут.
- Если месяц открыт — бюджет (или бюджет прошлого месяца), как сейчас.
- Каждое казино считается отдельно: в одном месяц может быть закрыт, а в другом ещё нет.
- Название строки и внешний вид не меняются.

## Проверка
- Сентябрь, все 4 казино: Estimated на Dashboard = Actual Expenses в Monthly Report по городам.
- Октябрь (открыт): цифры остаются без изменений.

## Технические детали
- Миграция `boss_monthly_report`: в `budget_agg` для казино с записью в `fin_month_closures` (year, month) вернуть сумму реальных расходов месяца в TZS — те же категории, что использует `use-fin-monthly-report` для `expensesActual` (без Collection/Money Change/Inter-Casino Transfer), плюс unplanned not in Actual. Для остальных казино текущий расчёт бюджета не меняется.
- Предварительно сверить SQL с `expensesActual` из `use-fin-monthly-report.ts`, чтобы источник был один.
- Поднять query key в `use-boss-monthly-report.ts`.
