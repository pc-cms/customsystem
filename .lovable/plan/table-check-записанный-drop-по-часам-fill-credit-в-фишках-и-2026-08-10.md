# Table Check: записанный Drop по часам, Fill/Credit в фишках и почасовке; золотой HeadCount

## Что сейчас (проверено)

- Drop в Table Check считается «на лету» каждые 15 секунд из транзакций за весь бизнес-день и показывается одной суммой в строке Drop — по часам он нигде не хранится.
- Часовые значения столов пишет триггер по снимкам фишек: он кладёт в слот только «сырую» дельту фишек (факт − ожидание). Fill и Credit в это значение НЕ входят.
- На вкладке Chips результат по столу уже включает Fill/Credit смены, но сами суммы Fill и Credit нигде не показаны, а в истории снимков к каждой строке добавляется полная сумма Fill/Credit смены (одинаково для всех часов), что искажает ранние часы.

## Что делаем

### 1. Drop записывается по часам и хранится

- Новая таблица хранения почасового Drop: на каждый бизнес-день, стол и часовой слот сохраняется сумма Drop, накопленная на момент записи.
- Запись происходит в тот же момент, что и часовой снимок фишек (та же логика слотов 19:00–06:00, включая Final), плюс кнопка ручной фиксации текущего часа.
- Страница Table Check показывает строку Drop по колонкам-часам из сохранённых записей (не пересчитывает), в конце — итог дня.
- Прошлые дни остаются как есть (исторические часы не восстанавливаются, там будет только итог).

### 2. Fill/Credit

- На вкладке Chips к каждому столу добавляются колонки Fill и Credit (за текущую смену) рядом с результатом, чтобы было видно, из чего он складывается.
- В почасовке Numbers значение слота становится: дельта фишек + (Credit − Fill), накопленные **до момента этого снимка**, а не за всю смену. Так каждый час учитывает только уже сделанные операции, и Final совпадает с закрытием смены.
- В истории снимков на вкладке Chips применяется та же логика «на момент снимка».

### 3. Statistics → Graphics

- HeadCount перекрашивается в золотой цвет (столбики + легенда + тултип).

## Технические детали

- Новая таблица `table_drop_tracker(casino_id, table_id, date, time_slot, amount)` с уникальным ключом (table_id, date, time_slot), GRANT + RLS по `has_casino_scope`.
- Правка `bridge_chip_snapshot_to_tracker()`: в том же цикле добавить (а) прибавление накопленного `Σcredit − Σfill` из `cage_transfers` с `created_at <= snapshot ts` к значению слота, (б) upsert накопленного Drop (`transactions` type in ('in','buy'), `cancelled_at is null`, `created_at <= ts`) в `table_drop_tracker`.
- Фронтенд: `src/pages/TableTracker.tsx` — строка Drop читает новую таблицу по слотам; `src/components/tables/ChipCountPanel.tsx` — колонки Fill/Credit и пер-снимочные корректировки; `src/components/reports/YearlyGraphicsReport.tsx` — золотой токен для HeadCount.
- Версия приложения повышается до **1.3.576**.
