# Coins — одно поле суммы вместо строк монет

Сейчас в каждой валюте под банкнотами стоят отдельные строки монет (USD 1 / 0.50 / 0.25 …). Это неверно: кассир не считает монеты по номиналам. Нужно одно поле «Coins», куда вписывается просто сумма мелочи.

## Как будет работать

- Под банкнотами каждой валюты — одна строка **Coins** с одним полем ввода.
- Вводится целое число мелких единиц: `105` в USD = 1.05 USD, `5` = 0.05 USD. То же для EUR, GBP, KES.
- Для TZS поле Coins тоже есть: там вводится просто сумма в шиллингах (монеты 50/100/200 и т.д.), без деления на 100.
- Итог по валюте включает Coins: банкноты + мелочь, с двумя знаками для валют и целым числом для TZS.
- Строки монет по номиналам убираются везде: кассы (открытие/закрытие смены, слоты), cash checks, Day Closing, Office Safe, Wallets, движения кошельков.
- В печатных отчётах и просмотрах вместо перечня монетных номиналов печатается одна строка «Coins» с суммой; итоги не меняются.

Ранее введённые данные с монетными номиналами не теряются: при просмотре и в суммах они сворачиваются в одну строку Coins.

## Технические детали

- `src/lib/currency.ts`: `COIN_DENOMS` удаляется; вводится `COIN_KEY(currency)` — ключ хранения `"0.01"` для USD/EUR/GBP/KES и `"1"` для TZS; `allDenoms()` возвращает только банкноты. Добавляется `splitCoins(map, currency)` — банкноты отдельно, сумма всех дробных/монетных ключей отдельно (совместимость со старыми записями).
- Хранение остаётся в том же jsonb-словаре номиналов: количество мелких единиц кладётся под ключ `0.01` (TZS — под `1`), поэтому `_sum_denoms` в БД суммирует корректно и миграция не нужна.
- `CashDenomInput`: секция монет по номиналам заменяется единым полем Coins (существующий механизм `cents`/`onCentsChange` переиспользуется и включается для всех валют); итог = `cashSum(notes) + coins * step`.
- Читающие места (`CashCheckViewerDialog`, `CashCheckNewGrid`, `CloseShiftDialog`, `ActiveSlotsShiftView`, `OpenSlotsShiftScreen`, `FinancesWalletsPage`, `FinancesOfficeSafePage`, `FinancesDayClosingPage`, `WalletMovementDialog`, `ReportPanels`, `TotalClosingReportV2` и остальные отчёты V2) переходят на `splitCoins` и печатают одну строку Coins.
- Печатный прогон `node scripts/print-tests/frozen-layout-print.mjs` перезапускается (ожидаемо 12/12), версия в `package.json` поднимается.
