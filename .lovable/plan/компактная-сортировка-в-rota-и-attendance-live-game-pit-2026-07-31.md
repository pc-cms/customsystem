# Компактная сортировка в Rota и Attendance (Live Game / Pit)

Сейчас над таблицами Rota и Attendance есть отдельная строка «Sort [Category / Name]», которая занимает целую полосу пустого места.

## Что меняем

- Убрать отдельную строку-тулбар сортировки над обеими таблицами.
- Перенести переключатель сортировки прямо в заголовок колонки **Name** таблицы (шапка `thead`), рядом с текстом «Name».
- Вид: компактная иконка-кнопка сортировки (стрелки) с всплывающим меню на два пункта — Category и Name (A–Z). Ширина колонки Name (180px) сохраняется, шапка не «разъезжается».
- Активный режим подсвечивается (иконка в цвете primary), подсказка при наведении показывает текущий режим.
- Элемент помечен `no-print`, чтобы не попадал в печатные версии роты/посещаемости.

## Где

- `src/pages/Pit.tsx`: блок Rota (строка ~894 и шапка ~909) и блок Attendance (строка ~1242 и шапка ~1257).
- Логика сортировки (`sortByCategory`, `rotaSort`, `attSort`, сохранение в sessionStorage) остаётся без изменений — меняется только место и вид контрола.

## Технические детали

Вместо `Select` в отдельном div — `DropdownMenu` (уже есть в проекте) с триггером `Button size="icon"` высотой 5–6 (h-5 w-5) и иконкой `ArrowUpDown`, вставленный внутрь `<th>` колонки Name через `flex items-center justify-between`. Никаких изменений в данных, хуках или БД.
