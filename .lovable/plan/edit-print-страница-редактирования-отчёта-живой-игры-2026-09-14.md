# Edit&Print: страница редактирования отчёта живой игры

## Задача
Кнопка Edit&Print открывает отдельную полноэкранную страницу, где можно править прямо в полях все цифры отчёта (Drop, фишки, филлы, кредиты, расходы, закрытие денег, безналичные) и сразу печатать. Сейчас часть правок — в первую очередь Drop, филлы, кредиты и результаты по столам — на печать не попадает.

## Почему Drop не меняется
Печатный бланк живой игры берёт строки по столам, Total Drop, безналичные и переводы из собственного источника (замороженный снимок закрытой смены или живые данные) и игнорирует значения, введённые на экране правки. Поля «расходы», «закрытие денег», «курсы», «результат», «баланс» передаются в бланк и работают, а всё, что связано со столами и Drop, — нет.

## Что сделаем

1. **Печать слушает правки.** Бланк живой игры и бланк движения фишек начнут принимать правки как приоритетный источник: строки по столам (открытие, филл, кредит, Drop, закрытие, результат), Total Drop, безналичные по провайдерам, добавление флота и выдача в слоты, банки/кошельки. Если правок нет — всё работает как сейчас, из замороженного снимка. Снимки закрытых смен не перезаписываются.

2. **Отдельная страница, а не окно.** Остаётся существующий адрес `/cage/shift/:id/edit-reprint`, но раскладку делаем удобной: слева поля ввода, справа живой предпросмотр четырёх страниц отчёта, сверху панель с кнопками «Back», «Reset», «Print».

3. **Полный набор редактируемых полей** на странице, все — инлайн-инпуты:
   - Касса: открытие и закрытие по каждой валюте + курсы.
   - Банки и мобильные кошельки: вход/выход/остаток по каждому каналу.
   - Фишки кассы: открытие/закрытие по номиналам, филл и кредит по номиналам, Miss.
   - Таблица по столам: Opening, Fill, Credit, **Drop**, Closing (по номиналам), Result.
   - Total Drop, расходы, чаевые, добавление флота, выдача в слоты.
   - Безналичные IN/OUT по каждому провайдеру.
   - Shift Balance и Table Result (с переключателем «авторасчёт / вручную», как сейчас).

4. **Ничего не сохраняется в базу.** Правки живут только в памяти страницы и влияют только на распечатку; ушли со страницы — исходные данные не тронуты. Наверху остаётся пояснение об этом.

5. Охват — только живая игра; слоты не трогаем.

## Технические детали
- `LiveClosingReportV2` / `ChipsMovementReportV2`: добавить необязательные пропсы-переопределения (`tableRowOverrides`, `totalDropOverride`, `cashlessOverride`, `cashFlowTransfersOverride`, `bankOverride`, `fillByDenomOverride`, `creditByDenomOverride`) и применять их поверх результата `useLiveShiftReportData` / снимка.
- `src/pages/EditReprintShiftPage.tsx`: остаётся страницей по маршруту `/cage/shift/:id/edit-reprint`; переработать раскладку на две колонки (форма + предпросмотр) и дополнить недостающими полями. `src/pages/Reports.tsx` без изменений — кнопка ведёт на страницу.
- Печать — существующий `printLiveGameReport` + `PrintPortal`, четыре страницы и ориентации без изменений.
- Правки только в UI-слое: расчётные функции, RPC и таблицы БД не меняются.
