# Безопасность: решения по первому списку и следующий список

## Первый список — по вашим ответам

2. **Полная очистка данных казино** — закрыть доступ всем. Программа её нигде не вызывает, поэтому ничего не сломается. Сама функция остаётся в базе, но запустить её из приложения никто не сможет.
3. **Проверка утёкших паролей** — сервер локальный, принимаем.
4. **Фото игроков** — так и должно быть, принимаем.
5. **Второе правило хранилища** — нормально, принимаем.

## Следующий список — принимаем все 6–15 (чтение нормально)
Каждую из этих таблиц может читать любой вошедший сотрудник любого казино. Менять данные они не могут.
6. **Коды смен** (shift_codes) — названия и часы смен всех казино.
7. **Категории расходов** (expense_categories) — список категорий.
8. **Финансовые категории** (fin_categories) — категории для финансовых отчётов.
9. **Основные финансовые группы** (fin_main_categories) — верхний уровень категорий.
10. **Настройки казино** (casino_settings) — служебные настройки каждого казино.
11. **Цвета фишек** (chip_color_settings) — цвета номиналов.
12. **Пакеты казино** (casino_packages) — какие модули включены.
13. **Модификаторы меню POS** (pos_modifier_menu_items) — к каким блюдам какие добавки.
14. **Списание склада по модификаторам POS** (pos_modifier_recipe_effects).
15. **Логотипы казино** (casino-branding) — файлы и так открыты по ссылке, видно только их список.

Моя рекомендация: принять все 6–15. Это справочники, без денег и личных данных, и экраны их используют. Исключение — **10 (настройки казино)**. Если не хотите, чтобы сотрудник одного казино видел настройки другого, могу ограничить её своим казино.
