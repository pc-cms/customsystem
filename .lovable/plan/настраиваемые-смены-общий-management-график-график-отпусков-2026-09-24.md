# Настраиваемые смены, общий Management-график, график отпусков

## 1. Буквы смен настраиваются для каждого казино и департамента

- Новая страница настроек **Shift Codes** (в Staff). Доступ: finance_manager, shift_manager, super_admin (+ boss, GM).
- Выбираешь казино + департамент (Live Game, Floor, Security, Office, Management) и видишь список букв.
- У каждой буквы: код (D, M, N, T…), время начала и конца (шаг 15 минут), цвет, флаг «рабочая / нерабочая» (L, A, S, O — 0 часов). Часы считаются сами из времени (смена через полночь считается правильно, например 18:00–06:00 = 12ч).
- Стартовые наборы заполняются из текущих значений (как сейчас в системе для Arusha/Dodoma/Staff), чтобы ничего не изменилось, пока не отредактируешь.
- Rota (план) и Attendance (факт) используют одни и те же буквы: в Rota выбираешь букву, Attendance автоматически подставляет её часы; ручная правка в Attendance остаётся главнее.
- **Пересчёт:** при изменении буквы часы пересчитываются только с 01/09/2026 и дальше (сентябрь и будущие месяцы). Август и раньше не трогаем — они хранят уже записанные часы.

## 2. Management Rota / Attendance видят все, правят только свой блок

- Страницу видят все роли с доступом к модулю, на любом домене — все блоки (Arusha, Dodoma, Mwanza, Mbeya, Office, CCTV).
- Редактирование:
  - Менеджер / shift manager на домене казино — только блок своего казино (зашёл на arusha — правит только Arusha).
  - finance_manager, boss, super_admin, GM — видят и правят все блоки.
  - CCTV (surveillance) — как сейчас, только блок CCTV.
- Чужие блоки показываются в режиме просмотра (без клика по клеткам). Проверка также на стороне базы, не только в интерфейсе.

## 3. Вкладка Vacations (график отпусков) в Management

- Новая вкладка рядом с Management Rota / Attendance.
- Строки — все менеджеры из общего списка Management, по алфавиту. CCTV тоже включаем в список? — по умолчанию только менеджеры.
- Колонки — месяцы года (12), каждый месяц визуально разбит на 3 части: 1–10, 11–20, 21–конец.
- Отпуск задаётся точными датами (начало и конец) + цвет. Отображается кубиком, растянутым по месяцам, с точной позицией внутри месяца (уехал 10-го — кубик с конца первой трети; переходит на следующий месяц, если отпуск через границу).
- Клик по кубику — окно с датами, цветом, заметкой; можно изменить или удалить.
- Правят: finance_manager, super_admin, boss, GM. Остальные только смотрят.
- Отпуск автоматически ставит **L** в Management Rota на эти дни (в слоте, где стоит этот человек в данном месяце). При удалении/сокращении отпуска эти L снимаются (только те, что поставил отпуск).

## Технические детали

- Таблица `shift_codes`: casino_id, department, code, start_time, end_time, hours (вычисляется), color, is_working, sort_order, unique (casino_id, department, code). GRANT + RLS: чтение аутентифицированным, запись — finance_manager/shift_manager/super_admin/boss/general_manager.
- Сид из текущих констант `src/lib/shift-hours.ts` (pit_arusha, pit_dodoma, staff, management D/M/N).
- `predictedShiftHours` заменяется хуком `useShiftCodes(casinoId, department)`; старые константы остаются fallback, если набор не заведён.
- Триггер на `shift_codes` update: пересчёт авто-часов в attendance (dealer/staff/management) для дат >= 2026-09-01 только там, где нет ручной правки.
- Management права: RPC-хелпер `can_edit_mgmt_block(slot_id)` — сравнивает casino_id слота с казино пользователя (домен/`profiles.casino_id`); network-роли — true. Используется в RLS `management_rota` / `management_attendance` / `management_slots`. Во фронте `ManagementGrid` получает `editableCasinoIds`.
- Таблица `management_vacations`: person_id, start_date, end_date, color, note, created_by; GRANT + RLS. Триггер вставляет/удаляет `management_rota` shift='L' с пометкой `source='vacation'` (новая колонка, default 'manual'); ручные смены не перезаписываются.
