# Table Check + Statistics: правки UI

## 1. Table Check — Drop вниз

Колонка Drop справа убирается. Вместо неё внизу таблицы появляется отдельная строка **Drop**, прямо перед строкой **Total**:

```text
Table    | 08:00 | 10:00 | ... | Final
AR1      |  ...  |  ...  |     |
AR2      |  ...  |  ...  |     |
DROP     |  (общий Drop за бизнес-день, справа)
TOTAL    |  тоталы по слотам
```

Значения Drop по столам остаются доступны в строке Drop (по одному значению на стол выводить негде, поэтому в строке показывается суммарный Drop дня, выровненный справа, тем же моношрифтом и стилем, что и сейчас). Источник Drop не меняется — Σ IN транзакций по бизнес-дню.

## 2. Statistics → Total: убрать плитку Total Hold

Из строки плиток убирается **Total Hold**. Остальные плитки (Drop Tables, Result Tables, Hold, Drop Slots, Result Slots, Hold, Total Result) остаются без изменений. Колонки таблицы не трогаем.

## 3. Statistics — порядок вкладок

Новый порядок: **Live Game · Slots · Total · …** (Total перемещается после Slots). Вкладка по умолчанию — Live Game.

## 4. Graphics — отсечка по завершённым месяцам и цвета

- График строится только по **завершённым** месяцам: текущий, ещё не закрытый месяц не рисуется. Линия обрывается на последнем полном месяце (для прошлых лет — все 12).
- Палитра переделывается: два «золотых/жёлтых» оттенка (Result Slots — warning, Drop Table — primary) заменяются на контрастные и максимально различимые цвета:

| Серия | Цвет |
|---|---|
| Drop Table | синий (primary/info-blue) |
| Result Table | зелёный (success) |
| Drop Slots | фиолетовый |
| Result Slots | розово-красный |
| HeadCount | серый (фоновые столбики) |

Цвета берутся из дизайн-токенов; при их нехватке добавляются новые HSL-токены в `index.css`, без хардкода в компоненте.
