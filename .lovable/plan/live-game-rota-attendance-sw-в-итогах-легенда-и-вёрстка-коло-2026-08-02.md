# Live Game Rota / Attendance: SW в итогах, легенда и вёрстка колонок

## Что не так сейчас (проверено в коде)

1. **SW не считается в итогах роты.** В таблице Rota (`src/pages/Pit.tsx`) итоговые колонки справа жёстко заданы как `M`, `N`, `E`, `Σh` — колонки SW нет, смены SW нигде не суммируются по сотруднику.
2. **Нижние строки-итоги по дням** содержат только `Σ M`, `Σ N` и `Σ All`. Строки `Σ SW` нет, а `Σ All` считает только `M`, `N` и Extra — SW из общего количества выпадает.
3. **Легенда Attendance неполная.** Показываются только `A` (Absent) и `S` (Sick), хотя система принимает ещё `SP` (Suspend) и `L` (Late), а также комбинации вида `8L` / `8S`.
4. **Возможное «налезание» колонок.** Итоговые строки закрывают хвост таблицы через `colSpan={4}`, а групповые заголовки — через `colSpan={days.length + 6}`. Эти числа зашиты вручную, поэтому при добавлении колонки SW сетка «поедет», если их не обновить. Также липкие колонки C (28px) и Name (180px) заданы фиксированными смещениями — проверю их совпадение во всех шапках (Dealers, Pit Bosses, Attendance).

Staff Rota (Floor / Security / Office) строит итоговые колонки динамически по списку смен группы — там SW не используется, проблема только в Live Game.

## Что делаю

**Rota (Live Game)**
- Добавляю колонку итогов **SW** между M и N (тот же фиолетовый цвет, что и в сетке), во всех трёх шапках: Dealers, Pit Bosses и печатная версия.
- Добавляю строку **Σ SW** по дням и включаю SW (и ESW) в строку **Σ All**.
- Итог **M** перестанет «съедать» SW: M считает только M/EM, SW — только SW/ESW, N — N/EN. Колонка E остаётся суммой всех Extra.
- Пересчитываю все `colSpan` (хвост 4 → 5, групповая строка +1), чтобы ничего не смещалось.

**Attendance (Live Game)**
- Дополняю легенду кодами `SP` (Suspend) и `L` (Late) с их цветами, добавляю подпись про формат `8L` / `8S` (часы + инцидент).
- Проверяю, что автозаполнение факта по SW/ESW берёт корректные часы (11h для Arusha и легаси-сетки) — логика уже есть, сверю значения.

**Проверка лейблов и вёрстки**
- Сверяю подписи смен в легенде с фактическими часами: Arusha — M 18:00–05:00 · 11h, SW 19:00–06:00 · 11h, N 20:00–06:00 · 10h; остальные казино — M 17:45 · 11h, SW 19:00 · 11h, N 20:45 · 8h.
- Прогоняю страницу в браузере (Rota и Attendance, Arusha и не-Arusha) со скриншотами: проверяю, что липкие колонки C / Name не перекрывают дни, шапка совпадает с телом таблицы по количеству колонок, легенда не наезжает на кнопки в шапке.
