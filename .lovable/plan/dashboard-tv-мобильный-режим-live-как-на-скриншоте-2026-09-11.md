# Dashboard TV — мобильный режим Live (как на скриншоте)

## Цель
Экран Boss → Dashboard TV в режиме Live (Today) должен красиво открываться на телефоне: та же информация, что на скриншоте (шапка с Total Drop / Total Result / Hold / Head Count / New Players и таблица казино TABLES / SLOTS / TOTAL × DROP / RESULT / HOLD), но без налезания цифр друг на друга. Данные, формулы и источники (`use-boss-dashboard`, `boss-display-metrics`) не трогаем — меняется только раскладка.

## Что делаем

### 1. Определение мобильного режима
- В `BossDashboard.tsx` используем `useIsMobile()` (breakpoint 768px, уже есть в проекте).
- На телефоне Live-режим переключается на новый компонент `MobileLiveStage` вместо `LiveStage` (стили Black/Red/Dark Gold на телефоне не применяются — один аккуратный тёмный вид). Company Report и десктоп не меняются.

### 2. Шапка (мобильная)
- Компактная строка бренда + дата + часы EAT (как сейчас).
- KPI-плитки: 2 ряда — первая строка `Total Drop` / `Total Result`, вторая `Hold` / `Head Count` / `New Players`. Каждая плитка: подпись мелко сверху, значение крупно снизу, `Num` с авто-подгонкой ширины (уже реализовано в `primitives.tsx`) — цифры не налезают.

### 3. Карточки казино (мобильные)
- Вместо одной широкой таблицы — вертикальный список карточек (по одной на казино), скролл по вертикали.
- В карточке: цветная полоса слева и название города (акцент города), строка `Head N`.
- Таблица внутри карточки: колонки `TABLES / SLOTS / TOTAL` как строки, колонки `DROP / RESULT / HOLD` компактные. Числа — моноширинные, с авто-fit (`useFitFactor`), перенос запрещён; при нехватке ширины шрифт уменьшается, а не наползает.
- Строка TOTAL выделена приглушённым золотом; RESULT — по существующей шкале `resultTone`.
- Top Players на телефоне не показываем (по скриншоту этой части нет); управление (выбор казино/стиль) остаётся доступным через панель настроек сверху.

### 4. Файлы
- Новый `src/components/boss/tv/mobile-live-stage.tsx` — мобильный Live-вид (переиспользует `Num`, `Kpi`, `fmtMoney/fmtSigned/fmtPct`, `resultTone`, `CityMark`).
- `src/pages/BossDashboard.tsx` — выбор `MobileLiveStage` при `isMobile && liveTv`; отключение `body overflow:hidden` на телефоне (нужен вертикальный скролл).

## Проверка
- Typecheck + сборка.
- Playwright на мобильном viewport (например 390×844): шапка, 4 карточки казино, длинные суммы (9–12 знаков) не налезают и не обрезаются; скриншоты.
- Десктоп 1920×1080 без изменений.
- Публикация не выполняется.
