# Wallets: месячная навигация в шапке

## Что меняем

В шапке страницы Wallets убираем набор пресетов периода (Today / Week / Month / Year / Custom) и ставим вместо него навигатор по месяцам: стрелка «влево», название месяца с годом (например «August 2026»), стрелка «вправо» и кнопка «This month».

Весь период страницы становится строго календарным месяцем: с 1-го по последнее число выбранного месяца. Это касается всех блоков — KPI, Breakdown (Expected), таблицы кошельков и списка Transactions (он уже считается по месяцу).

## Поведение

- По умолчанию открывается текущий месяц.
- Стрелки сдвигают месяц на -1 / +1; выбор сохраняется в сессии страницы, как сейчас сохраняется период.
- Подпись под Breakdown («Period …») показывает границы выбранного месяца.
- Заголовок блока Transactions продолжает показывать название месяца.

## Техническая часть

- `src/pages/finances/FinancesWalletsPage.tsx`: убрать `DateRangePresets`, `preset`/`presetRange`; хранить в `useSessionState` только `{ year, month }` и выводить `range = { from: первое число, to: последнее число }` через `useMemo`. Локальный `monthRange`/`monthLabel` станет основным источником периода.
- Для UI переиспользовать существующий `MonthCarousel` из `src/components/payroll/MonthCarousel.tsx` (стрелки + название месяца + «This month»), передавая `year`/`month` из состояния страницы, без URL-параметров.
- Логика запросов (`useFinBalanceSnapshot`, `useFinWalletTx`, физические подсчёты, Close Month) продолжает получать те же `from`/`to`, поэтому расчёты не меняются.
